# KRX Pattern B State Forward Return Study V01

## 1. 판정

**PATTERN_B_FORWARD_SIGNAL_MIXED**

LOW(DEPRESSED+DEEP_DEPRESSED)는 NORMAL보다 forward return의 median, 양(+) 수익 비율, ≥50% 비율이 네 horizon에서 대체로 높았고, PIT 시총 1조 원 이상 panel에서도 12/24개월 차이가 더 뚜렷했다. 다만 짧은 horizon의 차이는 작고, 이 이점이 DEEP_DEPRESSED까지 단조롭게 이어지지 않는다. 특히 ALL panel에서 DEEP_DEPRESSED는 NORMAL보다 median이 낮고 −30/−50% 손실 빈도와 MAE가 더 나빴다. 따라서 “가격이 낮을수록 항상 낫다”는 단순 명제는 지지되지 않으며, 상승 가능성과 꼬리 위험이 함께 관찰돼 verdict는 MIXED다.

출발 가설은 **부분적으로 지지된다**. 별도 Pure Pattern B 전략 백테스트를 탐색적으로 설계해 볼 만한 근거는 있지만, 전략 유효성이나 실전성을 확인한 것은 아니다. 이 연구에서는 후속 전략 백테스트를 실행하지 않았다.

## 7. MFE/MAE 관측 범위와 검증

- MFE/MAE 창은 snapshot 다음 session부터 정확한 horizon endpoint까지다. 무거래/정지일을 보간하지 않았고, 그 구간에서 Repository V2에 실제 존재하는 조정 high/low만 사용했다. 실제 가격봉 수는 horizon별 중앙값이 N과 같고, N일 전체 봉이 관측된 결과 비율은 아래와 같다.

| Horizon | 실제 가격봉 수 중앙값 / P10 | N일 전체 관측 비율 | 관측 봉 수가 N의 절반 미만인 비율 |
|---|---:|---:|---:|
| 3M | 63 / 62 | 87.4% | 0.02% |
| 6M | 126 / 123 | 84.1% | 0.02% |
| 12M | 252 / 245 | 80.6% | 0.06% |
| 24M | 504 / 489 | 75.4% | 0.19% |

- 미래 가격/상태 look-ahead random spot check 20건: 공식 evaluator와 상태·세 feature 값이 일치했고, PIT 입력 최종일이 snapshot을 넘지 않으며, forward 시작/끝 가격과 N번째 거래일 endpoint가 확인됐다. 기록: [lookahead_spot_checks.csv](lookahead_spot_checks.csv).
- Panel B exact PIT market-cap random spot check 20건: exact 날짜 raw snapshot 재조회와 1조 원 threshold를 확인했다. 기록: [pit_market_cap_spot_checks.csv](pit_market_cap_spot_checks.csv).
- Survivorship random spot check 20건: frontier 전에 끝난 terminal COMMON identity를 확인했고, 해당 snapshot은 PANEL A에 남아 있으며 identity 종료 후 endpoint horizon 결과는 생성되지 않았다. 기록: [survivorship_spot_checks.csv](survivorship_spot_checks.csv).
- Duplicate inflation: PANEL A key `(snapshot_date, ticker, ISU)` 중복 0, 같은 ticker/ISU의 달력 월별 중복 0; outcome key에 horizon을 추가한 중복 0. 월말 snapshot 외 일별 표본은 포함하지 않았다.
- 원인별 결과 미포함 집계는 [study_metadata.json](study_metadata.json), exact rows는 [snapshot_samples.csv.gz](snapshot_samples.csv.gz), [forward_outcomes.csv.gz](forward_outcomes.csv.gz)에 있다.

## 8. 핵심 발견 및 다음 단계

- LOW vs NORMAL의 median / win / ≥50% winner ratio 우위는 네 horizon 전반에 반복됐다. PANEL A에서 LOW의 median 우위는 3/6/12/24개월에 각각 약 +0.2/+0.2/+0.7/+4.4%p, ≥50% 비율 우위는 +0.3/+0.6/+2.6/+4.4%p다. PANEL B에서 median 차이는 +0.9/+1.5/+4.8/+8.8%p다.
- 12/24개월 PANEL A LOW의 ≥50% 결과 비율은 NORMAL보다 16.0% vs 13.4%, 23.1% vs 18.7%. 반면 ≤−50%는 4.4% vs 3.3%, 9.9% vs 8.3%, median MAE는 −25.1% vs −23.2%, −36.3% vs −32.8%로 손실 꼬리와 경로 낙폭이 커졌다.
- 성과는 DEPRESSED 상태에서 더 일관됐다. ALL panel DEEP_DEPRESSED의 12/24개월 median은 −5.4%/−7.7%로 NORMAL의 −3.6%/−5.0%보다 낮고, ≤−30% 비율은 19.1%/29.9%로 NORMAL 15.4%/24.2%보다 높았다. 반면 ≥50% winner는 deep에서도 NORMAL보다 조금 더 자주 나왔다. 평균 수익만으로 “deep이 더 낫다”고 결론 내릴 수 없는 비대칭 분포다.
- 따라서 “쌀 때 사면 이후 기대수익이 좋아지는가?”는 **부분 지지**다. 특히 DEPRESSED와 1조 원 이상 panel, 12/24개월에서 지지 신호가 크다. DEEP_DEPRESSED까지 같은 강도의 이점이 있다고 보기는 어렵다.
- Pure Pattern B 백테스트를 별도 작업으로 **탐색적으로 검토할 근거는 있다**. 그러나 이 결과만으로 전략 승인이나 실전성을 판단할 수는 없다. 다음 작업을 한다면 5-state별 기여도, deep의 −30/−50% 꼬리, 월별 중첩 표본, 거래/청산/비용 가정을 사전에 고정해야 한다. 후속 전략 백테스트는 실행하지 않았다.
