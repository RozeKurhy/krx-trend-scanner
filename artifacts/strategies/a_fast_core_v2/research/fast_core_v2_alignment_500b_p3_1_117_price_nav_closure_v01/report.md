P3-1 한 기간만 재판정했어. 평가 구간은 2022-01-03~2025-05-30, 정확한 KRX 평가일은 834일이고 2025-06-02는 cutoff 전에 발생한 신호의 체결 지원에만 사용했어. P1/P2-1/P2-2/P3-2 전체 실행, 전략 규칙 변경, P3-2 거래/신호 원장 복사, 외부 API 호출, 2,460종목 전체 재평가는 없었어.

기존 P3-1 미해결 목록의 정확한 117 ticker/ISU 쌍을 10 workers로 복원해 평가했어. 117개 모두 입력 가용, 조정가격 파일 hash 일치, PIT 내부 미해결 session 0, worker 오류 0이야. 후보 필터 재검증에서 신호 감사 82건: PASS 2, Alignment reject 36, MA window unavailable 30, 500B 미만 14. MA60 unavailable 30건은 선행 60개월 월봉 이력이 부족해 동결 규칙대로 거절된 거야. 새 CONTROL 신호 30건, 후보 신호 2건이 추가되어 두 포트폴리오를 2022-01-03부터 모두 순차 재생했어. 다른 2,343개 기존 입력/신호는 봉인 P3-1 hash 검증 후 재사용했어.
