## 결정과 범위

- 사용자 승인 예외 `(380440, KR7380440008)`를 **P3-2에서만**, CONTROL과 Alignment+500B의 공통 PIT 유니버스에서 신호 생성·현금 배분 전에 제외하는 뷰로 기록했어. 다른 표준 기간, 운영 전략, 웹, Daily Update, Strategy Monitor는 수정하지 않았어.
- 정확한 pair가 현재 COMMON PIT 원장에 한 건 있어(2021-05-21~2023-12-28). 기존 유니버스는 CONTROL과 후보가 공유하는 2,552개 ticker였고, 이 예외를 적용한 pre-signal 유니버스는 양쪽 모두 2,551개야. adjusted-price 파일 보유 수는 2,551→2,550, 해당 유니버스 내 파일 결측은 1→0이야. 후보의 전략별 후속 필터 통과 여부는 입력 가격이 없어 미확정이야. 상세는 `universe_exclusion_audit.csv`에 있어.
- 영구 제외 registry는 181쌍 그대로고 이 pair를 추가하지 않았어.

## 공식 기준 적합성

`docs/validation/backtest_common_rules.md` §2.6은 승인된 종목 제외를 영구 registry에 등록해 모든 전략과 P1/P2-1/P2-2/P3-1/P3-2에 공통 적용하도록 정해. 이번 승인 범위는 P3-2뿐이라 공통 기준과 충돌해. 다른 기간에 선제 적용하거나 영구 registry를 바꾸지 않았고, 기준 A도 자동 PASS로 올리지 않았어.

## 신호·거래·현금·NAV 불변성

- 조정가격 파일 부재로 closure의 대상 상태는 `NOT_EVALUATED`야. 따라서 제외는 “신호가 없었다”는 증거가 아니고, 완전한 데이터가 있었을 때의 잠재 신호 영향은 **UNKNOWN**으로 남겨.
- 기존 공식 P3-2 V01과 closure V01의 CSV를 identity 단위로 확인했어. 저장 신호 거래, 체결 거래, 현금 이벤트, 포트폴리오 이벤트, valuation mark, missing mark, skip 원장에는 이 identity의 행이 0개야. 발견된 두 행은 유니버스 가격 상태와 결측 입력을 기록한 진단 감사 행이야.
- 저장 결과에 대상 거래·현금·포트폴리오 행이 없어서 조건부 재생을 하지 않았어. 전체 신호 재실행과 포트폴리오 재생 없이 기존 closure V01 지표 61개를 그대로 대조했고, 저장 기록에 예외를 적용한 변화는 모두 0이야. 이건 **기존에 저장된 기록에 대한 no-op 검증**이고, 누락 데이터의 가상 신호 효과가 0이라는 뜻은 아니야. 파일별 행 수·해시는 `artifact_invariance_audit.csv`, 지표별 전후는 `metrics_comparison.csv`에 있어.
