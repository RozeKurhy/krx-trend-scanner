## A. 무결성 및 380440 정책 전환

- P3-2 closure 기준 커밋 `cbef18c7eed1d7002b16751b1000df2ce9851061`의 제외 목록은 181쌍이고, 해당 원본 파일 SHA-256은 기록된 값과 일치해. 현재 목록은 182쌍이며 정확한 set 비교 결과 `(380440, KR7380440008)` 하나만 추가됐고 삭제된 쌍은 없어.
- 현재 제외 파일 SHA-256은 `1c7cb7512024130f1ab0efa0ceb9f48ae0017a51af7f6db3f74d87b141a7d6ae`, 현재 schema `sorted_exact_pair_json_v01`로 재계산한 182쌍 canonical SHA-256은 지시서 값 `9091a40d5dfc3dc115e00166ea3ef806ef5a4ca3b595d76864598ec050904b12`와 일치해.
- 현행 공식 runner는 PIT 공통 유니버스를 구성할 때 exact `(ticker, ISU_CD)` 제외를 적용한 뒤 그 공통 유니버스를 두 그룹에 나눠. 과거 P3-2 예외 감사의 380440 필터도 CONTROL/후보 모두 신호 생성 전 같은 identity에 적용했어. 그러므로 현재 전 기간 정책은 공통 적용 조건을 만족해.
- 예전 P3-2 preflight의 181쌍 canonical 기록값은 그대로 보존했어. 당시 원본 제외 파일 SHA와 기준 커밋을 검증했고, 181→182 차이는 pair 목록을 직접 대조했어. 과거 기록값을 현재 schema로 다시 계산한 해시인 것처럼 취급하지 않았어.
- 제외 감사에 기록된 55개 기존 산출물을 다시 해시했고 55개 모두 일치했어. 그중 체결/포트폴리오 산출물 38개에서 380440 exact pair 행은 0개야. 가격 진단표에만 exact pair 진단 1행이 있어. 61개 지표의 제외 전후 값은 전부 동일해.
- 380440 조정가격 파일은 없어 신호 효과는 `UNKNOWN_NOT_EVALUATED`야. 저장 행이 없다는 사실을 신호 0건의 증거로 바꾸지 않았어. 이제 이 종목은 전 기간 공통 제외 대상이라 현재 공식 평가 유니버스 밖에 있고, 저장된 P3-2 결과의 거래·현금·성과 불변성도 확인돼.
- 복원된 123개 제한 가격 로딩은 123/123 성공, 파일 해시 123/123 일치, PIT 내부 세션 불일치 0, worker error 0이야. 완료된 신호를 다시 만들지 않았어.
- 최신 closure에는 코엔텍 `(029960, KR7029960002)` 체결 보유가 없어. CONTROL의 2024-11-18 진입 시도 한 건은 현금 부족으로 skip됐고 후보에는 이벤트가 없어. 최초 V01에 기록된 지급/정산 계약 미정 문제는 이력으로 보존했으며 임의 입금·매도·정산을 추가하지 않았어.
- 체결 생애주기를 이벤트에서 다시 구성한 결과, 매일 열린 포지션 수가 NAV 원장과 모두 일치하고 같은 종목 중복 보유는 없어. 계약상 인위적 최대 포지션 수는 없고 관측 최대 동시 보유는 CONTROL 48, 후보 52야. cutoff 이후 이벤트는 후보의 2026-09-01 지원일 청산 1건뿐이며 cutoff 성과/NAV에는 포함하지 않았어.

## B. 비용 및 현금 원장 재계산

기존 동결 계약 그대로 검산했어: 초기자본 2억원, 종목당 총 매수예산 500만원(수수료 포함), 정수주, 매수·매도 슬리피지 각 0.1%, 매수·매도 수수료 각 0.015%, 거래세 0%, 매도대금 T+1, 현금 부족 시 전량 skip 후 신호 원장은 재생성하지 않는 방식이야.

- 실제 매수 532건 모두 `floor(5,000,000 / (기준가 × 1.001 × 1.00015))` 정수주 수량과 일치했고, 총매수액+수수료가 500만원 이하여.
- cutoff 안의 체결 방향 1,003건(매수/매도)을 다시 계산했어. 체결가, 거래대금, 수수료, 슬리피지, 매도 미수금과 일별 가용현금 롤포워드가 저장 원장과 일치해. 현금/매도 미수금/일별 보유수량 재조정 최대 오차는 0원이야.
- CONTROL은 진입 시도 1,694건 중 1,388건 현금 부족 skip, 실체결 진입/청산/미청산 306/263/43건이야. 후보는 251건 중 25건 skip, cutoff 기준 226/208/18건이야. 지원일 후보 청산 1건은 별도로 제외했어. 현금 부족률은 공식 PASS/FAIL 게이트가 아니야.
- 수수료 합계는 CONTROL 430,518.34원, 후보 350,607.09원이고 슬리피지 영향은 각각 2,869,953.84원, 2,337,480.58원이야.
