해석은 다음과 같다.

- 수익성: Julia는 LONG RANGE total/CAGR에서 V3보다 11 대 5로 우세하다. SAME WINDOW는 Julia 8, V3 7, tie 1로 차이가 좁다.
- MDD: LONG RANGE는 V3 6, Julia 6, tie 4로 우열이 분명하지 않다. SAME WINDOW는 V3 7, Julia 3, tie 6으로 V3 쪽의 MDD 우위가 더 자주 나타난다.
- Matched mean/median: 두 기간 모두 Julia가 더 많은 섹터에서 우세하다.
- Matched MAE: V3가 LONG `12 대 0`, SAME `10 대 0`으로 less-negative MAE 우위를 보인다.
- 평균 보유기간: Julia가 V3보다 LONG 약 337일, SAME 약 346일 더 길다.
- 전략 성격: V3는 수익과 손실경로의 균형을 추구하고, Julia는 더 긴 보유로 상승 추세를 끝까지 보유하는 형태다.

## F. 최종 시사점

- Julia는 LONG RANGE에서 total/CAGR와 matched 평균 수익의 가장 강한 증거를 보인다.
- V3는 Julia보다 matched MAE에서 일관되게 덜 부정적이고, MDD도 특히 SAME WINDOW에서 상대적으로 자주 우세하다.
- V2는 필수소비재와 일부 금융·경기방어 성격 섹터에서 조기 Loss Guard의 장점이 나타난다.
- V4는 헬스케어·보험·일부 섹터의 MDD 방어에서 의미가 있으나, 범용 total/CAGR 경쟁력은 V3/Julia보다 제한적이다.
- 이 문서는 해당 표본의 증거만 정리하며 Julia의 공식 승격이나 전략 폐기 결론은 내리지 않는다.
- 다음 단계는 시장지수 ETF와 섹터 ETF를 통합한 V3 vs Julia 비교다.
