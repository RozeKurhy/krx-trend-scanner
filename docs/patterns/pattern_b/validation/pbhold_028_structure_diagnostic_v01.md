# Pattern B `PBHOLD_028` 구조 진단 V01

> 상태: 진단 완료. 규칙, 임계값, 지표, 사람 판정, 공식 평가는 바꾸지 않았다. 이 문서는
> 다음 연구 방향을 정하기 위한 근거이며 새 규칙 채택이 아니다.

진단 결과 원자료: [pbhold_028_structure_diagnostic_v01.json](pbhold_028_structure_diagnostic_v01.json)
(실행 스크립트 `scripts/diagnose_pattern_b_pbhold_028_v01.py`)

## 1. 대상

[사후진단 V01](holdout_v02_posthoc_adjudication_v01.md)에서 유일하게 남은 2단계 이상 오류다.

| 항목 | 값 |
|---|---|
| 사후 사람 판정 | `OVERHEATED` / `MEDIUM` (자동 판정을 본 뒤의 판정) |
| 상태 판정 규칙 V01 | `DEPRESSED` |
| `36M_RANGE_POSITION` | 0.2143 |
| `MONTHLY_MA24_DISTANCE` | +0.4339 |
| `52W_RANGE_POSITION` | 0.1384 |

공개 결과에는 종목코드, 기준일, 원래 가격을 넣지 않았다. 가격 관련 값은 모두 현재 종가 대비
비율이다.

## 2. 규칙안 C 결정 경로

봉인된 `feature_band()`와 `combine_bands()`를 그대로 호출했다. 중간 단계는 같은 함수에 다른
band를 넣어 확인했다.

| 단계 | 결과 |
|---|---|
| 36개월 범위 위치 band | 1 (`DEPRESSED`) — 주 상태 |
| MA24 이격 band | 3 (`OVERHEATED`) |
| 52주 범위 위치 band | 0 (`DEEP_DEPRESSED`) |
| 극단 완화 단계 | 적용 대상 아님 (주 상태가 극단이 아님) |
| 같은 쪽 확인 | 52주 범위 위치가 침체 쪽을 확인 |
| 최종 | `DEPRESSED` |

- 52주 band를 중립(NORMAL)으로 바꾸면 결과는 `NORMAL`이다. 즉 `DEPRESSED`를 유지시킨 것은
  52주 범위 위치의 확인이다.
- 52주 band를 그대로 두고 MA24 band를 0~4로 바꿔도 결과는 모두 `DEPRESSED`다.
- 주 상태가 `DEPRESSED`일 때 MA24·52주 조합으로 나올 수 있는 결과는 `DEPRESSED`와
  `NORMAL`뿐이다.

진단 질문 답:

1. `DEPRESSED`의 직접 원인은 36개월 범위 위치가 정한 주 상태다.
2. MA24의 과열 쪽 정보는 규칙안 C에서 "같은 쪽 확인" 역할만 한다. 반대쪽 신호는 주 상태를
   NORMAL로 되돌리지도, 반대편으로 뒤집지도 못한다.
3. 52주 범위 위치는 침체 쪽을 확인해 결과를 `DEPRESSED`에 고정했다.
4. 규칙안 C 구조상 반대 방향의 강한 MA24 신호가 주 상태를 반대편으로 뒤집는 경로는 없다.
   설계 때 의도한 성질(극단은 두 월봉 합의, 주봉은 확인만)의 결과다.

## 3. 기존 7개 지표

기존 `compute_pattern_b_features_v01()`로 계산했다. 이력 시작일은 별도 검증 표본 V02
원시값과 같은 종목 구간 시작일이다. 두 백분위 지표는 V01(1900년 시작)과 시작일 정책이 달라
참고값이다. "가장 가까운 V01 중앙값"은 사람 판정 V01의 판정 상태별 중앙값 중 가장 가까운
것으로, 방향을 읽기 위한 참고다.

| 지표 | 값 | 가장 가까운 V01 중앙값 | 방향 |
|---|---|---|---|
| `36M_RANGE_POSITION` (유지) | 0.214 | `DEPRESSED` | 침체 |
| `MONTHLY_MA24_DISTANCE` (유지) | +0.434 | `OVERHEATED` | 과열 |
| `52W_RANGE_POSITION` (유지) | 0.138 | `DEEP_DEPRESSED` | 침체 |
| `12M_RETURN_HISTORICAL_PERCENTILE` (제외) | 89.3 | `OVERHEATED` | 과열 |
| `36M_HIGH_DRAWDOWN` (제외) | −0.690 | `DEEP_DEPRESSED` | 침체 |
| `WEEKLY_MA40_DISTANCE` (제외) | −0.039 | `DEPRESSED` | 침체 |
| `26W_RETURN_HISTORICAL_PERCENTILE` (제외) | 95.7 | `EXTREME_OVERHEATED` | 과열 |

지표가 두 무리로 갈린다. 최근 범위의 고점을 기준으로 삼는 지표(범위 위치 2개, 고점 대비 하락
폭)와 주봉 MA40 이격은 침체 쪽이다. 장기 평균이나 과거 수익률 분포를 기준으로 삼는 지표(MA24
이격, 수익률 백분위 2개)는 과열 쪽이다. 제외한 지표 중 수익률 백분위 2개는 사후 판정과 같은
과열 방향이지만, 고점 대비 하락 폭은 범위 위치와 같은 고점 영향을 받는다.

## 4. 고점 스파이크 영향

| 항목 (현재 종가 = 1) | 값 |
|---|---|
| 최근 36개월 최저가 | 0.393 |
| 최근 36개월 최고가 | 3.225 |
| 최근 36개월 종가 중앙값 | 0.610 |
| 최근 84개월 종가 중앙값 | 0.610 |
| 24개월 이동평균 | 0.697 |
| 최근 52주 최저가 / 최고가 | 0.577 / 3.225 |
| 36개월 최고가 이후 경과 | 2개월 (52주 기준 10주) |

현재 종가는 최근 36개월·84개월 종가 중앙값의 약 1.64배이고, 24개월 이동평균보다 43% 높다.
그런데 2개월 전 고점이 현재 종가의 3.2배라, 범위 위치의 분모(최고가 − 최저가)가 크게
늘어났다. 그래서 현재 가격이 장기 일반 가격대보다 높은데도 범위 위치는 하단(0.21, 0.14)으로
나온다. 인위적인 고점 제거 같은 조작은 하지 않았다.

## 7. 다음 연구 방향 제안: `FEATURE_RESEARCH_JUSTIFIED`

- 핵심 원인은 범위 위치 지표가 최근 스파이크 고점에 크게 끌려가는 표현상의 한계다. 36개월과
  52주 범위 위치가 같은 고점 영향을 함께 받아, 규칙안 C에서 주 상태와 확인 신호가 동시에 같은
  방향으로 왜곡됐다.
- 규칙 변경만의 근거는 약하다. 같은 유형은 V02 36개 중 이 1건뿐이고, 사후 판정은 자동 판정을
  본 뒤의 `MEDIUM` 판정이다. MA24가 주 상태를 뒤집게 하는 식의 규칙 수정은 이 한 사례에 맞춘
  조정이 될 위험이 크다.
- 따라서 범위 위치 계열이 최근 급등락 고점에 덜 민감하게 현재 위치를 표현하는 방법을 먼저
  지표 연구로 검토하는 것을 제안한다. 규칙(`RULE_V02`) 연구 여부는 그 결과와 새 별도 검증 표본
  V03에서 판단한다. 이 제안은 연구 방향이며, 새 지표나 규칙을 이번에 정하지 않았다.

바꾸지 않았다. 별도 검증 표본 V02는 이후 규칙 검증에 다시 쓰지 않는다.
