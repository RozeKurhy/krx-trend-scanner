# Pattern B 상태 판정 규칙 V02 검증 전략 V01

> 상태: 판단 완료. 결론은 `HUMAN_VALIDATION_NOT_REQUIRED_FOR_RULE_DEFINITION`이다.
> 규칙 V02, 임계값, 사람 판정, 봉인 파일은 바꾸지 않았다. 새 별도 검증 표본은 만들지 않았고,
> 새 사람 판정도 요청하지 않았다.

## 1. 목적 정의

| 구분 | 내용 | 이번 판단에서의 위치 |
|---|---|---|
| A. 결정적 상태 규칙 | 종목 자신의 장기 가격 사이클에서 현재 상태를 일관되고 재현 가능하게 분류한다. 같은 입력이면 항상 같은 상태가 나온다 | 주목적 |
| B. 사람 판정 모사 | 사용자의 육안 판정을 최대한 높은 정확 일치로 복제한다 | 목적이 아님 |

Pattern B 상태 판정 규칙 V02는 **봉인된 결정적 상태 규칙**으로 정의한다. 각 상태 이름
(`DEEP_DEPRESSED` 등)의 뜻은 [규칙 V02](state_rule_v02.md)의 계약(유지 지표 3개, 임계값,
판정 순서)이 정한다. 사람 판정은 이 정의가 사용자의 "현재 상태" 개념과 크게 어긋나지 않는지
보는 **의미 참고 자료**다. 경계 상태에서는 절대 정답으로 취급하지 않는다.

## 2. 기존 사람 판정의 한계

기존 기록에서 확인할 수 있는 근거만 적는다.

| 근거 | 기록 | 확인한 내용 |
|---|---|---|
| 판정 기준의 변화 | [사후진단 V01](holdout_v02_posthoc_adjudication_v01.md) | 공식 대형 오류 7개를 "현재 상태 우선"으로 다시 보니 6개가 공식 판정과 2~4단계 달라졌고, 1개(`PBHOLD_028`)는 1단계 달라졌다. 재판정은 자동 판정을 안 상태에서 했으므로 가려진 판정이 아니다 |
| 판정 기준 V02의 성격 | [사람 판정 기준 V02](human_ground_truth_criteria_v02.md) §6 | 판정 순서 2~4단계가 유지 지표 3개의 개념과 가깝다. 이 기준으로 한 판정은 설계상 지표와 더 잘 맞을 수 있다 |
| 개발 표본 판정 절차 | [개발 표본 V02 사람 판정](development_v02_human_labels.md) | 초기 `MEDIUM` 표본을 재검토했다. 판정자는 규칙 V01의 개략적 설계를 알고 있었다 |
| 중간 위치인데 극단 판정 | `PBDEV2_019` | 사람 `DEEP_DEPRESSED`/`MEDIUM`, 유지 지표 3개는 모두 중간 위치(36M 0.282, MA24 +0.033, 52W 0.489) |
| 한 단계 안의 불일치 | [지표 평가 V01](development_v02_feature_evaluation_v01.md), [규칙 V02](state_rule_v02.md) | 개발 표본 V02에서 규칙 V01·V02 모두 35/36이 1단계 이내다 |
| 판정 흔들림의 크기 | 없음 | 같은 판정자의 반복 판정이나 두 번째 판정자 기록이 없다. 사람 판정 자체의 흔들림 크기는 측정되지 않았다 |

해석:

- 사람 판정은 판정 기준 문구에 따라 크게 달라졌다(기준 V01 → V02). 경계 사례에서 한 단계
  차이를 규칙 실패로 단정하지 않는다. 2단계 이상 차이나 방향이 반대인 차이를 더 중요한 경고로
  본다.
- 한쪽 방향으로 몰린 한 단계 차이는 흔들림이 아니라 **규칙 정의와 사용자 개념의 체계적 차이**로
  기록한다. 규칙 V02는 개발 표본에서 사람 `DEPRESSED` 12개 중 6개를 `NORMAL`로 판정한다. 즉 규칙
  V02의 `DEPRESSED`는 사용자의 `DEPRESSED`보다 좁다.
- 이 규칙 계열의 유일한 독립 사람 평가는
  [규칙 V01의 별도 검증 표본 V02 공식 평가](state_rule_v01_holdout_v02_evaluation.md)다. 그 결과는
  정확 일치 12/36, 2단계 이상 오류 7개로 나빴다. 사후진단의 반사실 수치(17/36, 1개)는 공식
  수치가 아니다. 이 사실은 그대로 남긴다.

## 3. 규칙 V02 자동 검증

구현 계약은 `tests/test_pattern_b_state_v02.py`(14개, 모두 통과)와
[봉인 파일](state_rule_v02_seal.json)로 고정되어 있다.

| 항목 | 고정 내용 | 테스트 |
|---|---|---|
| 전체 band 조합 비교 | 125개 조합을 모두 V01과 비교 | `test_only_deep_36m_with_depressed_ma24_differs_from_v01` |
| V01 대비 변경 조합 | 정확히 5개(`m36`=DEEP, `ma24`=DEP, `w52` 무관), 모두 DEP → DEEP | 같은 테스트 |
| 과열 쪽 | 결과가 NORMAL 이상인 모든 조합에서 V01과 같다. EXT는 두 월봉이 모두 극단일 때만 | `test_overheated_side_is_v01` |
| DEEP 조건 | DEEP은 `m36`=DEEP이고 `ma24`가 침체 쪽일 때만 | `test_deep_needs_deep_36m_and_depressed_side_ma24` |
| 단조성 | 세 입력 중 하나를 올리면 상태가 내려가지 않는다 | `test_monotone_in_every_input` |
| 임계값 불변 | V01의 임계값 객체를 그대로 쓴다. 36M 경계 0.25 | `test_thresholds_and_features_are_v01` |
| 잘못된 입력 | 유한한 숫자가 아니면 오류 | `test_non_finite_or_non_numeric_input_fails` |
| 봉인 | 구현·기록·연구 결과의 SHA-256, 개발셋 수치 | `test_seal_integrity` |
| 보호 입력 | 사람 판정, 기준 V02, 규칙 V01, 별도 검증 표본 V02 파일의 SHA-256 | `test_protected_files_are_unchanged`, `test_seal_integrity` |
| 개발셋 재현 | 36개 예측이 연구 A1/B0와 같다. 22/36, 35/36, MAE 0.4167, 2단계 이상 1개, DEEP 9/11 | `test_reproduces_research_a1_b0_on_development_v02` |
| 별도 검증 표본 미참조 | 규칙 코드에 별도 검증 표본 참조가 없다 | `test_no_holdout_reference_in_rule` |

추가 라벨 미사용 점검은 하지 않았다. 기존 도구로 새로 얻을 정보가 위 항목보다 크지 않고, 새
분석 도구를 만들지 않는 원칙을 따랐다.

## 4. 판단 질문

### 질문 1. 새 사람 별도 검증 표본이 규칙의 "정확성"을 검증할 수 있는가

아니다. 결정적 규칙의 정확성은 두 가지로 나뉜다.

- **계약대로 계산하는가**: 3절의 자동 검증으로 확인된다. 사람 판정이 필요 없다.
- **상태 이름이 의도한 개념에 맞는가**: 사람 판정이 줄 수 있는 정보는 이것뿐이다. 그것도
  판정자 1명과의 일치도로만 잴 수 있다.

게다가 새 판정은 규칙에 대해 가려진 판정이 될 수 없다. 판정자는 이제 규칙 V02의 설계를 자세히
알고, 기준 V02는 설계상 지표와 가깝다(2절). 따라서 새 표본의 일치도는 규칙의 정확성이 아니라
"이 판정자가 이 기준으로 본 결과와 얼마나 비슷한가"다.

### 질문 2. 새 표본 16개가 의미 있는 추가 정보를 줄 가능성이 충분한가

제한적이다. 이항 분포로 계산했다(새 분석 도구 없음).

- 정확 일치 10/16이 나와도 95% 신뢰구간(Wilson)은 0.39~0.82다. 개발셋 22/36(0.45~0.75)과
  구분되지 않는다.
- 참 정확 일치율이 0.61일 때, 16개로 "V01 독립 평가 수준(0.33)보다 높다"를 보일 검정력은 약
  0.75다. 큰 실패를 걸러 내는 정보는 어느 정도 있다.
- 2단계 이상 오류율이 개발셋 수준(1/36)이면 16개에서 한 건도 안 나올 확률이 0.64다. 오류율이
  5%여도 0.44다. 대형 오류가 0건이어도 강한 근거가 아니다.
- 16개를 5개 상태에 나누면 상태당 약 3개다. 가장 약한 과열 쪽(개발 표본 OVH 4, EXT 1)의 의미를
  확인하기에 부족하다.
- 규칙을 다시 튜닝하지 않으므로, 결과가 규칙을 바꾸지 않는다. 결과가 바꿀 수 있는 것은
  "사람 일치도를 주장할 수 있는가"뿐이다.

남는 가치는 "사용자 개념과 크게 어긋나는 대형 실패가 있는지"를 거칠게 보는 것이다. 이
가치는 사람 일치도를 공식 품질 지표로 쓸 때만 필요하다.

### 질문 3. 구현 계약이 충분히 고정되어 있는가

그렇다. 규칙 V02는 V01에 분기 하나를 더한 최소 변경이다. 3절처럼 125개 전체 band 조합,
V01 대비 변경 5개, 단조성, 임계값 불변, 구현·기록 SHA-256, 보호 입력 SHA-256, 개발셋 재현이
테스트와 봉인으로 고정되어 있다. 규칙이 바뀌면 테스트가 실패한다.

### 질문 4. 사람 검증 없이 끝내면 포기하는 주장

- 규칙 V02의 독립 사람 판정 일치도(정확 일치, 1단계 이내, MAE, 대형 오류율)
- 규칙 V02가 새 표본에서 V01보다 사람 판정과 더 잘 맞는다는 주장
- 개발 표본 V02 수치(22/36 등)가 새 종목·새 기준일에서도 나온다는 일반화
- 과열 쪽(`OVERHEATED`, `EXTREME_OVERHEATED`)이 사람 판정 기준 V02의 개념과 맞는다는 주장
- 규칙 V02의 `DEPRESSED` 범위가 사용자의 `DEPRESSED` 개념과 같다는 주장
- 규칙 V01의 별도 검증 표본 V02 결과가 사후진단으로 해소되었다는 주장

### 질문 5. 사람 검증 없이도 할 수 있는 주장

- 규칙 V02는 봉인된 결정적 상태 규칙이다. 같은 입력이면 같은 상태가 나온다.
- 규칙 V02는 규칙 V01과 125개 band 조합 중 5개에서만 다르다. 과열 쪽과 나머지 로직은 V01과
  같다.
- 상태의 순서가 입력과 단조적으로 움직인다.
- 규칙 V02는 개발 표본 V02에서 22/36 정확 일치, 35/36이 1단계 이내였다. 이 수치는 개발용
  참고 성능이다.
- 개발 표본에서 V01의 DEEP → DEP 차이 7개 중 6개가 규칙 변경 하나로 없어졌다(새 차이 1개).
- 규칙 V02의 상태 의미는 문서화된 지표·임계값·판정 순서로 정의된다.

## 5. 결론: `HUMAN_VALIDATION_NOT_REQUIRED_FOR_RULE_DEFINITION`

사람 검증을 생략하는 조건 6개를 모두 만족한다.

| 조건 | 충족 방법 |
|---|---|
| 1. 사람 판정 모사 모델이 아니라 봉인된 결정적 상태 규칙으로 정의 | 1절 |
| 2. 독립 사람 별도 검증 성능을 주장하지 않음 | 4절 질문 4, README |
| 3. 개발 표본 V02 수치를 일반화 성능으로 표현하지 않음 | 4절 질문 5, [규칙 V02](state_rule_v02.md) 머리말, 봉인 파일의 `DEVELOPMENT_SET_ONLY_NOT_HOLDOUT` |
| 4. 계약·임계값·V01 대비 차이·한계를 문서화 | [규칙 V02](state_rule_v02.md) 1·2·4절, 이 문서 2·3절 |
| 5. 사람 판정과의 한 단계 차이를 절대 오류로 보지 않음 | 2절 |
| 6. 규칙 V02를 다시 튜닝하지 않음 | 6절 |

사람 검증이 필요한 조건은 현재 해당하지 않는다.

- 사람 판정과의 높은 정확 일치를 공식 품질 지표로 주장하지 않는다.
- 규칙 V02의 확정은 독립 사람 판정 성능에 의존하지 않는다.
- `DEEP_DEPRESSED`와 `EXTREME_OVERHEATED`의 뜻은 규칙 계약이 정의한다.

## 6. 운영 원칙

- 규칙 V02는 결정적 상태 규칙으로 봉인되어 있다.
- 규칙 V02의 독립 사람 별도 검증 성능은 없다.
- 개발 표본 V02 수치는 개발용 참고 성능이다.
- 사람 판정은 의미 참고 자료이며, 경계 상태의 절대 정답으로 취급하지 않는다.
- 현재 규칙을 추가 튜닝하지 않는다. 규칙을 바꾸려면 새 버전으로 만들고, 바꾼 이유와 한계를
  따로 기록한다.
- 별도 검증 표본 V02는 소진되었으므로 다시 쓰지 않는다.
- 이전 기록의 "별도 검증 표본 V03 24개" 계획은 폐기되었고 되살리지 않는다.

앞으로 사람 판정 일치도를 공식 품질 지표로 주장해야 하는 목적이 생기면, 그때 이 판단을 다시
검토한다. 그 경우에도 가린 별도 검증 표본은 최대 16개로 한다.
