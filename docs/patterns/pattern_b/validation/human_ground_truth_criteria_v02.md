# Pattern B 사람 판정 기준 V02 — 현재 상태 우선

> 상태: 설계·봉인 완료. 앞으로 새로 하는 사람 판정(별도 검증 표본 V03 이후)에만 적용한다.
> 기존 사람 판정 V01·V02와 공식 평가, 사후진단은 이 기준으로 다시 해석하지 않는다.

## 1. 목적

[사람 판정 기준 V01](human_ground_truth_v01.md)을 대체하지 않고, 다음 판정에서 기준이 흔들리지
않도록 "현재 상태"를 먼저 보는 원칙을 명확히 한다. 이 원칙은
[별도 검증 표본 V02 사후진단 V01](holdout_v02_posthoc_adjudication_v01.md)에서 정리한 기준
후보를 바탕으로 한다.

## 2. 핵심 원칙

### 현재 상태 우선

Pattern B 상태는 평가 시점의 **오른쪽 마지막 가격이 자기 장기 가격 사이클에서 현재 어느
위치에 있는지**를 먼저 판정한다. 과거 상태와 현재 상태는 분리한다. 과거에
`EXTREME_OVERHEATED`였다는 사실이 현재도 `EXTREME_OVERHEATED`라는 뜻은 아니다.

### 왼쪽 시작 가격 대비 배수를 쓰지 않는다

차트 왼쪽 시작 가격을 100으로 두고 현재가 200이니 두 배라서 과열이라고 판정하지 않는다.
차트 시작점은 표시 기간에 따라 달라지는 임의 기준점이므로 상태 판정의 직접 기준이 아니다.

### 과거 최고점은 현재 상태를 유지시키지 않는다

100 → 400 → 200 경로에서 과거 400은 과거 과열의 증거일 수 있지만, 현재 200의 상태는 현재
장기 위치로 다시 판정한다.

### 고점 대비 하락 폭만으로 침체로 보지 않는다

400 → 200이라고 해서 자동으로 `DEPRESSED`나 `DEEP_DEPRESSED`가 아니다. 현재 200이 장기 가격
영역에서 실제로 어디에 있는지 본다.

### 극단 상태

- `DEEP_DEPRESSED`: 단순히 많이 떨어진 상태가 아니다. 현재 가격 자체가 장기 사이클의 하단
  극단에 있고, 월봉에서 장기간 눌려 있으며, 주봉도 현재 저점권의 극단성을 보조로 확인하는
  상태다. 이동평균 아래로 내려갔다는 것 하나만으로 주지 않는다.
- `EXTREME_OVERHEATED`: 과거 급등 흔적이 아니라, 현재 가격이 장기 사이클의 상단 극단에 여전히
  있는 상태다. 과거 폭등 뒤 장기간 하락해 현재 위치가 내려왔다면 현재 상태를 다시 판정한다.

### 월봉 핵심, 주봉 보조

월봉이 핵심이고 주봉은 현재 극단성을 보조로 확인한다. 주봉 하나만으로 월봉과 반대 상태를
만들지 않는다.

### 과거 경로는 별도 축 후보

과거 경로가 연구에 필요하면 현재 5단계 상태와 분리해 별도 축으로 다룬다. 예를 들면 현재
상태 `DEPRESSED`와 과거 경로 "최근 극단 과열"을 따로 기록하는 방식이다. 이 기준에서는 과거
경로 체계를 만들지 않고, 경계만 기록한다.

## 3. 판정 순서

1. 오른쪽 마지막 가격을 먼저 본다.
2. 월봉 전체에서 현재 가격이 장기 가격 영역의 상단·중간·하단 중 어디인지 본다.
3. 최근 수년 범위에서 현재 위치를 확인한다.
4. 장기 평균 대비 현재 위치를 눈으로 참고한다.
5. 주봉으로 현재 극단성이 이어지는지 보조로 확인한다.
6. 과거 급등·폭락은 맥락으로만 쓴다.
7. 판단이 애매하면 신뢰도를 낮추거나 판정 보류(`UNCERTAIN`)를 쓸 수 있다.

## 4. 상태 정의 (현재 상태 기준)

| 판정 값 | 현재 상태 |
|---|---|
| `DEEP_DEPRESSED` | 현재 가격이 장기 사이클의 하단 극단에 있다 |
| `DEPRESSED` | 현재 가격이 장기 사이클의 아래쪽에 있으나 극단은 아니다 |
| `NORMAL` | 현재 가격이 아래·위 어느 극단에도 가깝지 않다 |
| `OVERHEATED` | 현재 가격이 장기 사이클의 위쪽에 있으나 극단은 아니다 |
| `EXTREME_OVERHEATED` | 현재 가격이 장기 사이클의 상단 극단에 있다 |

`UNCERTAIN`은 사람 판정 작업용 보조 기록 값으로 유지하며, 정식 상태가 아니다. 수치 임계값은
두지 않는다.

## 5. 경계 예시 (개념)

- **예시 A**: 100 → 400 → 200. "과거에 극단 과열이었다"와 "현재 상태"를 나눈다. 현재 200이
  장기 가격대에서 어디인지 다시 본다.
- **예시 B**: 오랫동안 대부분 80~150이었고 한때 400까지 갔다가 현재 200. 현재 200은 과거 일반
  가격대보다 높을 수 있으므로, 고점 대비 하락 폭만 보고 침체로 판정하지 않는다.
- **예시 C**: 현재 가격이 장기 범위와 최근 범위 모두의 하단 극단이고 주봉도 저점을 갱신한다.
  `DEEP_DEPRESSED` 후보가 강해진다.

## 6. 방법론 한계

- 이 기준은 별도 검증 표본 V02 공식 평가와 사후진단이 끝난 뒤, 자동 판정 결과를 본 상태에서
  설계했다.
- 따라서 별도 검증 표본 V02를 다시 해석하거나, 상태 판정 규칙 V01의 독립 검증 성공을 주장하는
  데 쓸 수 없다. V02는 다시 평가하지 않는다.
- 이 기준은 앞으로 새로 하는 사람 판정(V03 이후)에만 쓴다.
- 판정 순서 2~4단계(장기 범위 위치, 최근 범위 위치, 장기 평균 대비 위치)는 유지 지표 3개가
  보는 개념과 가깝다. 그래서 이 기준으로 한 사람 판정은 설계상 지표와 더 잘 맞을 수 있으며,
  이후 평가를 해석할 때 이 점을 고려한다.
