# Pattern B 개발 표본 V02 사람 판정

> 상태: 36개 판정 완료·봉인. 개발 표본의 지표 계산과 자동 판정은 아직 하지 않았다. 이
> 표본은 개발용이며 별도 검증 표본이 아니다.

## 목적과 입력

[개발 표본 V02](development_v02_protocol.md)의 식별정보를 가린 차트 36개(`PBDEV2_001`~
`PBDEV2_036`)를 [사람 판정 기준 V02](human_ground_truth_criteria_v02.md)(현재 상태 우선)로 판정한
결과를 봉인한다. 이 판정은 지표 후보와 상태 판정 규칙 V02 연구의 기준으로 쓴다.

## 판정자와 절차

- 판정자: 사용자 1명. 최종 상태와 신뢰도는 모두 사용자가 결정했다.
- 초기 판정 뒤 신뢰도 `MEDIUM` 표본을 재검토했다. 봉인한 값은 사용자의 마지막 명시 판정이며,
  이전 중간 판정을 모두 대체한다. 이전 중간 판정값은 기록하지 않았다.
- 판정자는 지표 값과 자동 판정을 보지 않았다. 대화형 AI는 일부 표본에서 사용자의 명시 판정 뒤
  차트 해석 메모를 제공했으나, 최종 상태와 신뢰도는 사용자의 마지막 명시 판정만 사용했다.
- 판정자는 상태 판정 규칙 V01의 존재와 개략적 설계를 알고 있었다. 따라서 규칙에 대해 완전히
  가려진 판정은 아니다.
- 이 저장소에 기록·봉인한 작업에서는 사용자가 확정한 판정표를 받아 그대로 옮겼고, 값을 고치지
  않았다.

## 판정 파일

[development_v02_human_labels.csv](development_v02_human_labels.csv) (`sample_id,label,confidence`,
36행)

판정 이유 메모(`note`) 열은 두지 않았다. 판정이 끝난 뒤 메모를 복원하면 사후 작성이 되기
때문이다.

## 결과

| 판정 상태 | 표본 수 |
|---|---|
| `DEEP_DEPRESSED` | 11 |
| `DEPRESSED` | 12 |
| `NORMAL` | 8 |
| `OVERHEATED` | 4 |
| `EXTREME_OVERHEATED` | 1 |

신뢰도는 `HIGH` 35개, `MEDIUM` 1개(`PBDEV2_019`), `LOW` 0개다.

## 봉인과 이후 절차

이 문서와 판정 파일은 [development_v02_human_labels_seal.json](development_v02_human_labels_seal.json)의
SHA-256으로 봉인한다. 지표 값이나 자동 판정을 본 뒤 이 판정을 고치지 않는다. 수정이 필요하면
새 버전으로 기록한다.

다음 단계에서만 개발 표본의 지표 값(기존 지표와 대안 후보)을 계산·공개하고, 지표와 상태 판정
규칙 V02를 연구한다.
