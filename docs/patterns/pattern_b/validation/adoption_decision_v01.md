## 1. 역할 명확성 — PASS

근거:

- [개념 기준](../spec/README.md) "목적"은 기업가치가 아니라 종목 자신의 장기 가격 사이클에서
  현재 가격이 장기 침체 쪽인지 과열 쪽인지를 판단한다고 정한다. 바닥·천장 예측이 아니다.
- 입력: 조정 가격 일봉에서 계산한 월봉 지표 2개, 주봉 지표 1개
  ([지표 계약 V01](../spec/feature_contract_v01.md), [규칙 V02](state_rule_v02.md) 1절).
- 출력: `DEEP_DEPRESSED`, `DEPRESSED`, `NORMAL`, `OVERHEATED`, `EXTREME_OVERHEATED` 중 하나.
- 매매 신호가 아님: 개념 기준 "상태 후보"에 "매수·보유·매도 신호가 아니다", "다른 영역과의 경계"에
  "매수·매도 규칙, 투자 수익률, 백테스트 결과"를 정의에 넣지 않는다고 적혀 있다.
- 기업가치 평가가 아님: 개념 기준에 Pattern B의 "싸다"는 자기 과거 가격 대비 침체이며 기업가치
  대비 싸다는 뜻이 아니라고 적혀 있다.

남는 한계: 개념 기준은 가치 함정·구조 붕괴 위험을 걸러 내지 않는다고 적는다. 적격성·위험 판단
층은 정하지 않았다.

## 2. 기존 패턴과의 차별성·비중복성 — PASS

| 패턴 | 무엇을 보는가 | 주된 출력 | 근거 |
|---|---|---|---|
| Pattern A | 장기 베이스를 거친 뒤 장기 추세가 상승 쪽으로 전환되기 시작하는가. 베이스(과도하게 확장되지 않음)와 추세 전환(MA24 기울기 등)을 함께 본다 | Score 0~100, Stage `WEAK`·`BASE`·`TRANSITION`·`EARLY_TREND`·`PROGRESSED` | [Pattern A 공식 규격](../../pattern_a/spec/production_authority.md) 3~5절 |
| Pattern A FAST | 장기 환경이 허용되는 종목에서 주봉 구조가 유효한 상승 전환으로 발전하기 시작했는가 | 주봉 생애주기 `WATCH`·`SETUP`·`TRIGGER`·`TREND`·`EXTENDED` | [FAST 정의](../../pattern_a_fast/spec/README.md), [주봉 생애주기](../../pattern_a_fast/spec/weekly_lifecycle.md) |
| Pattern B | 현재 가격이 자기 장기 가격 범위와 장기 평균 대비 어느 수준에 있는가. 아래·위 양쪽을 대칭으로 본다 | 5단계 상태 `DEEP_DEPRESSED` ~ `EXTREME_OVERHEATED` | [개념 기준](../spec/README.md), [규칙 V02](state_rule_v02.md) |

"왜 별도의 공식 패턴으로 존재해야 하는가?"

- Pattern A와 A FAST의 출력은 **상승 전환 과정의 생애주기**다. 기울기와 구조 변화로 판정하고,
  전환이 없으면 상태도 전환 관점으로만 표현된다.
- Pattern B의 출력은 **추세나 전환과 무관한 가격 수준**이다. 전환이 시작되지 않은 종목에도
  "장기 하단 극단인가"를 답한다. 특히 침체 쪽(`DEEP_DEPRESSED`, `DEPRESSED`)은 A·A FAST에 대응하는
  출력이 없다. A의 `WEAK`는 진행 중인 하락을 뜻하고, 가격이 자기 범위의 어디에 있는지를 뜻하지
  않는다.
- 개념 기준도 A·A FAST의 전환 구조를 Pattern B 정의에 섞지 않는다고 정한다.

겹치는 부분:

- 같은 조정 가격 데이터를 쓴다. Pattern A도 가격 범위 안 위치와 비슷한 개념의 지표를 Stage
  맥락으로 쓴다. 두 산식이 같은지는 이 판단에서 확인하지 않았다.
- Pattern B의 `OVERHEATED`·`EXTREME_OVERHEATED`는 Pattern A의 `PROGRESSED`, A FAST의 `EXTENDED`와
  개념이 일부 겹친다. 다만 A·A FAST의 것은 상승 전환 이후 진행 정도이고, Pattern B의 것은 자기
  가격 범위 대비 수준이다.

공통 기준은 완전한 무상관을 요구하지 않는다. 출력 의미와 관찰 축이 실질적으로 다르므로 통과로
본다. 이 판단은 Pattern A·A FAST의 상태를 다시 판정하지 않는다.

남는 한계:

- 계산 불가일 때 상태를 내지 않는다(오류). 이 동작은 결정적이지만, "상태 없음"을 나타내는 출력
  값(예: A FAST의 `UNAVAILABLE`)은 정의되어 있지 않다. 운영 연결 단계에서 규칙을 바꾸지 않고
  정해야 한다.
- 종목 구간 규칙(기준일을 포함하는 PIT COMMON 종목 구간 안에서만 가격을 읽고 다른 구간과 이어

  [원시 지표값 V02](feature_raw_values_v02.md)에 있다. 규칙 V02의 근거 자료는 모두 이 규칙으로
  계산했다. 권위 문서에서 이 두 문서로 연결한다. 운영 대상 종목 범위 규칙을 새로 만들지 않았다.

## 4. 결정성·재현성 — PASS

근거:

- 규칙 V02는 band 비교와 분기만 쓰는 결정적 함수다. 같은 지표 값이면 같은 상태가 나온다.
- `tests/test_pattern_b_state_v02.py` 14개 통과. 이 테스트가 고정하는 내용은 다음과 같다.
  - 125개 band 조합 전체를 V01과 비교한다. V01과 다른 조합은 정확히 5개다.
  - 과열 쪽은 V01과 같다.
  - 입력에 대해 단조적이다.
  - 임계값 객체는 V01과 같다.
  - 잘못된 입력은 오류를 낸다.
  - 개발 표본 V02 36개 예측을 재현한다.
- [봉인 파일](state_rule_v02_seal.json): 구현 SHA-256 `72adacfa…b37e`, 기록 SHA-256 `a0a5a290…8bc2`,
  보호 입력 14개의 SHA-256. 이번 작업 시점에 구현과 기록 SHA-256이 봉인값과 같았다.
- Pattern B 전용 테스트 140개 통과.

남는 한계: 일봉에서 상태까지 한 번에 계산하는 단일 함수는 없다. 구현은 지표 계산
`compute_pattern_b_features_v01`과 상태 판정 `classify_pattern_b_state_v02`의 조합이다. 이번
작업에서 연결 함수를 만들지 않았다.

## 5. 목적에 맞는 검증 완료 — PASS (불리한 근거 포함)

Pattern B 규칙 V02의 목적은 사람 판정 모사가 아니라 결정적 상태 정의다
([검증 전략 V01](state_rule_v02_validation_strategy_v01.md)). 이 목적에 맞는 검증은 계약 재현
테스트와 봉인이며, 4절처럼 완료되었다. 사람 판정은 의미 참고 자료로 썼다.

함께 기록하는 근거:

| 구분 | 내용 |
|---|---|
| 기존 독립 검증 | 이 규칙 계열의 유일한 독립 사람 평가는 [규칙 V01의 별도 검증 표본 V02 공식 평가](state_rule_v01_holdout_v02_evaluation.md)다. 정확 일치 12/36, 1단계 이내 29/36, 2단계 이상 오류 7개였다. 별도 검증 표본 V02는 소진되었다 |
| 사후진단 | [사후진단 V01](holdout_v02_posthoc_adjudication_v01.md)에서 대형 오류 7개 중 6개의 사후 판정이 공식 판정과 2~4단계 달랐다. 자동 판정을 안 상태의 재판정이므로 가려진 판정이 아니다. 반사실 수치(17/36)는 공식 수치가 아니다 |
| 개발 검증 | 개발 표본 V02에서 규칙 V02는 정확 일치 22/36, 1단계 이내 35/36, MAE 0.4167이다. 같은 표본으로 후보를 골랐으므로 개발용 참고 성능이다 |
| 사람 검증 | 규칙 V02의 독립 사람 검증 성능은 없다. [검증 전략 V01](state_rule_v02_validation_strategy_v01.md)에서 규칙 정의에는 추가 사람 검증이 필요 없다고 결정했다 |

실패 사례와 한계:

- `PBHOLD_028` 유형: 급등 뒤 급락해 범위 위치는 낮지만 현재 가격이 장기 평균보다 크게 높은 경우,
  규칙은 침체 쪽으로 보고 사용자는 과열 쪽으로 봤다. 규칙 V02는 이 경우를 바꾸지 않았다.
- 규칙 V02의 `DEPRESSED`는 사용자 개념보다 좁다. 개발 표본에서 사람 `DEPRESSED` 12개 중 6개가
  `NORMAL`이었다.
- 과열 쪽은 개발 표본이 적어(OVH 4, EXT 1) 사용자 개념과의 일치를 말할 수 없다.
- 기준일에 거래정지 중인 종목은 마지막 거래 봉으로 상태가 계산된다. 검증 표본은 이런 종목을
  제외했다.
- 규칙을 전체 종목에 적용해 본 적이 없다. 상태 분포와 계산 불가 비율을 모른다.

적용 범위: 규칙 V02의 근거 자료는 KRX PIT COMMON 종목 구간(ETF 제외)의 Repository V2 조정
가격이며, 완료 월봉 36개·주봉 52개 이상이 필요하다.

이 채택은 다음 주장을 하지 않는다.

- 규칙 V02가 사람보다 정확하다.
- 규칙 V02의 독립 사람 일치도가 검증되었다.
- 개발 표본 22/36이 일반화된다.
- Pattern B가 수익률을 개선한다.

## 6. 현재 권위 확정 — PASS

이번 작업에서 [Pattern B 공식 규격](../spec/production_authority.md)을 만들었다. 이 문서는 새
산식이나 규칙을 복제하지 않고, 다음을 한곳에 연결한다.

- 공식 패턴 이름, 현재 상태, 현재 상태 판정 규칙(V02)
- 지표 계약, 규칙 계약, PIT·종목 구간 근거 문서
- 구현 위치
- 운영 상태: 스캐너·일일 갱신·웹에 연결되지 않음
- 알려진 한계, 독립 사람 검증 성능이 없다는 제한
- 전략·매매 신호가 아니라는 경계, 연구 기록과 현재 기준의 구분

## 결론: 공식 패턴 (`OFFICIAL_PATTERN`)

기준 6개를 모두 충족한다. Pattern B는 상태 판정 규칙 V02를 현재 규칙으로 하는 공식 패턴이다.
공식 패턴은 공식 전략, 수익성, 매수 추천을 뜻하지 않는다.

운영 연결(운영 계약, 전체 종목 점검, 일일 갱신·웹 연결 여부)은 이 판단의 범위가 아니며 별도로
결정한다.
