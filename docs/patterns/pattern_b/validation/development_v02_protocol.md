# Pattern B 개발 표본 V02 절차 (사람 판정 기준 V02용)

> 상태: 표본과 식별정보를 가린 차트 묶음 생성·봉인 완료. 사람 판정은 아직 없다. 이 표본은
> 개발용이며 별도 검증 표본(Holdout)이 아니다.

## 목적

[사람 판정 기준 V02](human_ground_truth_criteria_v02.md)를 처음 적용할 새 개발 표본 36개를
만든다. 이 표본에서 지표 후보와 상태 판정 규칙 V02를 연구한 뒤, 최종 검증은 완전히 별도의
별도 검증 표본 V03으로 한다.

## 표본 계약

- 36개 표본, 36개 서로 다른 종목, 표본 식별자 `PBDEV2_001`~`PBDEV2_036`.
- 기준일: 2019·2021·2023·2025년 각각 12월 31일 이하의 마지막 KRX 거래일. 기준일마다 9개다.
  사람 판정 V01(2021·2023·2025년 6월 말)과 별도 검증 표본 V02(2020·2022·2024·2026년 6월 말)와
  겹치지 않는 시점이다.
- 사람 판정 V01의 본·예비 종목과 별도 검증 표본 V02의 36개 종목은 모두 제외한다. 두 표본과
  종목·기준일이 같은 표본은 없다.
- 기준일 12월 31일은 KRX 휴장이라 기준일이 12월 30일 전후가 된다. 완료된 봉 규칙에 따라 12월
  월봉은 아직 완료되지 않은 것으로 보고 빠진다.

## 선정 방법

사람이 종목을 고르지 않는다. [별도 검증 표본 V02 절차](holdout_v02_protocol.md)와 같은 방식이다.

1. 기준일에 유효한 PIT COMMON 종목 구간 중 제외 종목을 뺀 후보를
   `sha256("PATTERN_B_DEVELOPMENT_V02|<기준일>|<ticker>")` 순서로 정렬한다.
2. 앞에서부터 검사해 데이터 조건(종목 구간 안 조정 가격, OHLC 검증, 완료 월봉 84개·주봉
   156개, KRX 달력 기간 일치, 기준일 시점 거래 존재)을 통과한 첫 9개를 채택한다. 이전 기준
   연도에서 채택한 종목은 다시 쓰지 않는다.
3. 조건을 못 채운 후보는 건너뛴다. 수동 교체는 하지 않는다.

선정에는 사람 판정, 상태 판정 규칙, 지표 값(기존·대안 후보 모두), 미래 수익률을 쓰지 않는다.

## 가림과 공개 범위

사람 판정이 모두 끝날 때까지 판정자에게 종목명, 종목코드, 기준일, 지표 원시값(기존 범위 위치,
MA24 이격, 대안 후보 포함), 상태 판정 규칙 V01·V02의 자동 판정, 기존 유사 표본 정보를 보여주지
않는다. 판정은 사람 판정 기준 V02만 따른다.

생성 스크립트: `scripts/build_pattern_b_development_v02_chart_pack.py`

차트 계약과 파일 위치: [development_v02_chart_pack.md](development_v02_chart_pack.md)

봉인: [development_v02_seal.json](development_v02_seal.json)

## 이후 순서

1. 개발 표본 V02 생성·봉인 (이 문서)
2. 사람 판정 기준 V02로 36개 사람 판정 → 봉인
3. 봉인 뒤에만 지표 값을 계산·공개하고 지표·규칙 V02 연구
4. 최종 검증은 새 별도 검증 표본 V03으로 1회
