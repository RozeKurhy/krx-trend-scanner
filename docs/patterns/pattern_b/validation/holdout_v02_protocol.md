# Pattern B 별도 검증 표본(Holdout) V02 절차

> 상태: 표본과 식별정보를 가린 차트 묶음 선봉인 완료. 사람 판정, 지표 계산, 자동
> 판정은 아직 하지 않았다. 상태 규칙 V01이 봉인되기 전까지 이 표본은 열어 보지 않는다.

## 목적

상태 규칙과 임계값을 [사람 판정 V01](human_ground_truth_v01.md) 36개에만 맞춰 과적합하는
위험을 줄이기 위해, 상태 규칙 설계 전에 별도 검증 표본과 차트 묶음을 먼저 고정한다.
[지표 선택 V01](feature_selection_v01.md)의 표본 한계에서 요구한 검증 표본이다.

## 표본 계약

- 36개 표본, 36개 서로 다른 종목. 한 종목은 한 번만 쓴다.
- 기준 연도 4개(2020, 2022, 2024, 2026) × 연도별 9개.
- 기준일: 각 연도 6월 30일 이하의 마지막 KRX 거래일. KRX 거래일 달력으로 코드가 정한다.
  V01 기준일(2021·2023·2025년)과 겹치지 않는다.
- 후보: 기준일에 유효한 PIT COMMON 종목 구간(유효 기준 자료인 effective authority의
  `effective_pit_common_denominator`). ETF는 포함하지 않는다.
- V01 차트 묶음의 본 종목과 예비 종목(`PRIMARY_TICKERS`, `BACKUP_TICKERS`)은 V01 생성
  스크립트에서 직접 읽어 모두 제외한다.

## 선정 방법

사람이 종목을 고르지 않는다. 기준 연도 순서(2020 → 2026)로 다음을 반복한다.

1. 후보를 `sha256("PATTERN_B_HOLDOUT_V02|<기준일>|<ticker>")` 순서로 정렬한다.
2. 앞에서부터 검사해 아래를 모두 만족하는 첫 9개를 채택한다.
   - 이전 기준 연도에서 이미 채택한 종목이 아니다.
   - 기준일을 포함하는 COMMON 종목 구간 안에서 Repository V2 조정 가격을 읽을 수 있다.
     구간 시작일부터 기준일까지만 읽어 다른 종목 구간과 이어 붙이지 않는다.
   - 조정 OHLC가 모두 유한한 양수이고 `low <= open, close <= high`다.
   - 완료된 월봉 84개 이상, 주봉 156개 이상이 있다.
   - 모든 봉이 KRX 달력 기간과 맞는다.
   - 기준일의 마지막 완료 월·주에 거래가 있다. 기준일에 거래정지 중인 종목은 최신 가격이
     오래된 값이라 건너뛴다.
3. 조건을 채우지 못한 후보는 건너뛰고 다음 후보로 간다. 수동 교체는 하지 않는다.

기준일 이전에 끝난 거래정지는 탈락 사유가 아니다. 선정에는 Pattern B 지표,
Pattern A / A FAST, 상대강도, 펀더멘털, 미래 수익률, 사람 판정 결과를 쓰지 않는다. 선정
결과는 무작위 추출과 같아서, 상태별 표본 수는 사람 판정 전에는 알 수 없다.

## 차트 계약

[차트 묶음 V01](chart_pack_v01.md)과 같다.

- 월봉 84개(위), 주봉 156개(아래), 완료된 봉만 사용, Repository V2 조정 가격
- 1600×1200 PNG, 흑백 캔들, 선형 y축, 패널별 첫 종가를 `100`으로 정규화(표시용)
- 거래량, 이동평균, 지표, 종목명, 종목코드(ticker), 날짜 표시 없음
- 거래정지 기간은 x축에 실제 시간 공백으로 남긴다.
- 차트에는 `sample_id`만 표시한다.

## 가림과 비공개 파일

- 표본 선정은 결정적이다. `sample_id`(`PBHOLD_001`~`PBHOLD_036`) 대응만 운영체제 난수로
  한 번 섞고, 다시 실행하면 저장된 대응을 재사용한다. 대응이 다르면 실패한다.
- 비공개 파일은 `artifacts/pattern_b_holdout_v02/private/`(권한 700·600)에 두고 Git에
  올리지 않는다. 대응표는 Git 밖(`~/krx_private_backups/pattern_b_holdout_v02/`)에도
  백업했다.
- 봉인 증거는 [holdout_v02_seal.json](holdout_v02_seal.json)이다. 대응표와 차트 묶음 ZIP의
  SHA-256만 담고 종목코드·종목명·기준일 대응은 담지 않는다.
- 확인 작업에서 차트 이미지를 볼 때는 `sample_id`를 가린 사본을 쓰고, 종목코드·기준일과
  `sample_id`를 한 사람에게 함께 보여주지 않는다.

생성 스크립트: `scripts/build_pattern_b_holdout_v02_chart_pack.py`

## 상태 규칙 봉인 전 금지 사항

상태 규칙 V01이 봉인되기 전까지 다음을 하지 않는다.

- 비공개 대응표 열람
- 가린 차트의 수동 판정
- 별도 검증 표본 사람 판정(HGT V02) 기록
- 별도 검증 표본 지표 계산
- 별도 검증 표본 자동 상태 평가

그동안 상태 규칙 설계는 사람 판정 V01 36개와 유지 지표 3개만 쓴다.

## 이후 순서

1. 별도 검증 표본 V02와 차트 묶음 선봉인 (이 문서)
2. 사람 판정 V01 36개로 상태 규칙·임계값 연구
3. 상태 규칙 V01 봉인
4. 별도 검증 표본의 가린 차트 사람 판정
5. 별도 검증 표본 판정 결과(HGT V02) 봉인
6. 봉인된 규칙으로 별도 검증 표본 지표 계산과 자동 판정
7. 사람 판정과 자동 판정을 1회 비교

별도 검증 표본 평가 결과를 본 뒤 V01 임계값을 고치면 이 표본은 더 이상 검증 표본이 아니다.
고친 규칙은 새 검증 표본으로 다시 평가해야 한다.
