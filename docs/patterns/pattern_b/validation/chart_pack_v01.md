# Pattern B 사람 판정 차트팩 V01

> 상태: V01 차트팩 생성 완료. 36개 표본의 사람 판정을 마쳤고, 결과는
> [human_ground_truth_labels_v01.csv](human_ground_truth_labels_v01.csv)에 봉인했다.
> 판정 원칙은 [사람 판정 기준 V01](human_ground_truth_v01.md)을 따른다.

이 문서는 사람 판정 기준 V01에서 다음 작업으로 미뤘던 표본과 차트 표시 방식을
V01 차트팩에 한해 고정한다. Feature 산식, 임계값, 자동 판정 규칙은 여전히 정하지
않는다.

## 표본

- 12종목 × 기준일 3개 = 36개 표본. Feature 값이나 이후 성과와 무관하게 사전에
  고정했다.
- 종목: `005930`, `000660`, `005380`, `035420`, `051910`, `005490`, `068270`,
  `090430`, `011200`, `034020`, `086520`, `035900`
- 기준일: `2021-06-30`, `2023-06-30`, `2025-06-30`
- 예비 종목: `003490`, `010950`, `017670`, `009150` 순서. 한 종목이라도 세 기준일
  중 필요한 이력을 제공하지 못하면 그 종목의 3개 표본 전체를 다음 예비 종목으로
  바꾼다. 교체 사유는 데이터 부족과 종목 동일성(identity) 문제만 허용한다.

## 차트

- 가격: Repository V2 조정 가격을 기준일까지만 읽는다.
- 월봉: 기준일까지 완료된 월봉 84개. 주봉: 기준일까지 완료된 주봉 156개(금요일
  마감 기준). 진행 중인 기간은 넣지 않는다.
- 모든 봉은 KRX 거래일 달력의 기간과 일치해야 한다. 해당 종목의 거래가 전혀 없던
  기간(거래정지)은 봉을 만들지 않고 건너뛰며, 이때 표시 구간은 달력상 84개월·156주보다
  길어진다. 거래정지는 예비 종목 교체 사유가 아니다.
- 거래정지 기간은 x축에서도 실제 시간 공백으로 남긴다. 봉의 x 위치는 첫 봉 기준 달력상
  월·주 순번이며, 공백에 가짜 봉, 앞 값 채우기, 보간, 0 가격을 넣지 않는다.
- 한 PNG에 월봉(위)과 주봉(아래)을 배치한다. 흑백 캔들만 그리며 거래량, 이동평균,
  Feature 표시는 없다.
- 가격은 화면 표시용으로만 각 패널의 첫 종가를 `100`으로 정규화한다. y축은 선형
  눈금이며, 축 범위는 화면에 보이는 봉만으로 계산한다.
- x축에는 날짜를 표시하지 않는다. 종목명, ticker, 기준일도 표시하지 않는다.

## 가림(blind) 처리

- 36개 표본을 한 번 무작위로 섞어 `PBHGT_001`~`PBHGT_036`을 붙인다. 섞은 결과는
  비공개 manifest에만 저장한다.
- 판정자용 묶음에는 PNG 36개와 `annotation_template.csv`
  (`sample_id,label,confidence,note`)만 넣는다.
- 같은 종목이 세 기준일에 모두 나오므로, 뒤 기준일 차트에 앞 기준일 이후의
  가격 흐름이 들어 있다. 판정자는 표본을 나란히 비교하지 말고 한 장씩 판정한다.
