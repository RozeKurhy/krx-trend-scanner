# Pattern B 사람 판정 V02 (별도 검증 표본)

> 상태: 36개 판정 완료·봉인. 별도 검증 표본의 지표 계산, 자동 상태 판정, 사람 판정과
> 자동 판정의 비교는 아직 하지 않았다.

## 목적

[별도 검증 표본 V02 절차](holdout_v02_protocol.md)에 따라 선봉인한 식별정보를 가린 차트
36개를 사람이 판정하고, 그 결과를 봉인한다. 이 판정은 봉인된
[상태 판정 규칙 V01](state_rule_v01.md)을 1회 검증하는 기준으로 쓴다.

## 판정자와 입력

- 판정자: 사용자 1명. 36개 표본의 최종 상태와 신뢰도는 모두 사용자가 결정했다.
- 판정 과정에서 쓴 AI는 사용자의 판정 뒤 메모 문구를 정리했다. `PBHOLD_009`에서는
  이 AI가 실수로 사용자보다 먼저 `OVERHEATED` / `MEDIUM` 의견을 1회 제시했다. 사용자는
  이 의견을 채택하지 않고 `NORMAL` / `MEDIUM`으로 직접 최종 판정했다. 그 외 표본에서는
  AI가 사용자보다 먼저 상태 판정을 제시하지 않았다.
- 이 저장소에 판정 결과를 기록·봉인한 작업에서는 사용자가 확정한 36개 판정표(메모
  포함)를 받아 그대로 옮겼고, 상태·신뢰도·메모를 고치지 않았다.
- 입력: 선봉인한 차트 묶음(`pattern_b_holdout_v02_blind_pack.zip`)의 PNG 36장
  (`PBHOLD_001`~`PBHOLD_036`). 새 차트 생성, 표본 재선정, 표본 식별자 재배치는 하지 않았다.
- 차트는 [차트 묶음 V01](chart_pack_v01.md)과 같은 계약(완료된 월봉 84개·주봉 156개,
  식별정보·날짜·지표 표시 없음)을 따른다.

## 판정 기준

[사람 판정 기준 V01](human_ground_truth_v01.md)을 그대로 썼다.

- 질문: 현재 가격이 이 종목 자신의 장기 가격 사이클에서 어디쯤 있는가?
- 월봉을 우선하고 주봉은 보조로 본다. 가격 위치만 판단하며 기업가치, 향후 상승 가능성,
  매수·매도 여부는 판단하지 않는다.
- 판정 값은 `DEEP_DEPRESSED`, `DEPRESSED`, `NORMAL`, `OVERHEATED`,
  `EXTREME_OVERHEATED` 5개이며, 판정 보류(`UNCERTAIN`)는 최종값으로 쓰지 않았다.
- 신뢰도
  - `HIGH`(높음): 월봉 중심 인상이 명확하고 주봉도 크게 충돌하지 않는다.
  - `MEDIUM`(보통): 경계성이 있으나 최종 판단이 가능하다.
  - `LOW`(낮음): 상당히 애매하지만 판정자가 최종 상태를 골랐다.

## 판정 절차

1. `PBHOLD_001`부터 차례로 표본마다 상태, 신뢰도, 짧은 메모를 기록했다.
2. 36개가 모두 입력될 때까지 상태별 개수 같은 중간 집계를 보지 않았다.
3. 36개 판정표를 판정자가 최종 확인한 뒤, 그대로 봉인했다.

## 가림 범위와 알려진 한계

판정자는 상태 판정 규칙 V01의 존재와 개략적 설계 내용을 알고 있었다. 따라서 이 판정은
규칙에 대해 완전히 가려진 판정은 아니다. 다만 별도 검증 표본의 다음 정보는 36개 사람
판정 완료와 봉인 전까지 보지 않았다.

- 종목명, 종목코드, 기준일, 비공개 대응표
- 유지 지표 3개의 실제 값
- 자동 상태 판정 결과
- 미래 수익률

또한 `PBHOLD_009`에서 AI의 선행 상태 의견이 1건 있었다. 사용자는 이 의견을 채택하지
않았고, 최종 판정은 사용자가 직접 정했다.

이 한계를 이유로 판정 결과를 보정하지 않았다.

## 봉인과 이후 절차

이 문서와 판정 결과 파일은 [human_ground_truth_v02_seal.json](human_ground_truth_v02_seal.json)의
SHA-256으로 봉인한다. 자동 판정 결과를 본 뒤 V02 판정을 고치지 않는다. 수정이 필요하면
V02를 덮어쓰지 않고 새 버전으로 기록한다.

다음 단계는 별도 검증 표본 V02의 유지 지표 3개를 계산하고, 봉인된 상태 판정 규칙 V01을
적용해 사람 판정 V02와 1회 비교하는 것이다.
