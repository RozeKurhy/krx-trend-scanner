# Pattern B 개념 기준

> 상태: 공식 패턴 (`OFFICIAL_PATTERN`). 이 문서는 Pattern B의 개념과 경계를 정한다. 현재
> 기준 문서와 구현 위치는 [Pattern B 공식 규격](production_authority.md)을 따른다. 전략 규칙과
> 백테스트는 없다.

## 목적

Pattern B는 다음 질문에 답하기 위한 공식 패턴이다.

> 기업가치가 아니라 종목 자신의 장기 가격 사이클을 기준으로 볼 때, 월봉과
> 주봉에서 가격이 장기 침체 상태인가, 장기 과열 상태인가?

일반 투자자는 오래 외면받아 가격이 크게 눌린 종목은 피하고, 오래 올라 가격이
크게 확장된 종목은 뒤따라 사는 경향이 있다. Pattern B는 이런 행동과 반대편에
있는 두 가격 상태를 기계적으로 관찰하려는 것이다.

- 장기간 외면받고 가격이 자기 역사 대비 극단적으로 눌린 상태
- 장기간 상승해 가격이 자기 역사 대비 극단적으로 확장된 상태

Pattern B는 바닥이나 천장을 예측하는 패턴이 아니다. 현재 가격이 자기 장기
사이클 안에서 어느 쪽 극단에 가까운지를 판단할 뿐이다.

## 다른 영역과의 경계

| 영역 | 역할 | Pattern B와의 관계 |
|---|---|---|
| Pattern A / A FAST | 상승 구조와 상승 전환 탐지 | 별도 패턴. 전환 구조를 Pattern B 정의에 섞지 않는다 |
| Pattern B | 자기 장기 가격 사이클 내 침체·과열 상태 탐지 | 이 문서 |
| 향후 Pattern C (구상 단계) | 수급 상태 | 외국인·기관 수급을 Pattern B에 섞지 않는다 |
| 향후 Pattern D (구상 단계) | 펀더멘털·기업가치 | 기업가치 평가와 OpenDART 재무를 Pattern B에 섞지 않는다 |

다음 내용은 Pattern B 정의에 포함하지 않는다.

- 기업가치 판단(Valuation)과 OpenDART 재무(Fundamentals)
- 외국인·기관 수급
- 시장·업종 상대강도(Relative Strength)
- Pattern A / A FAST의 상승 전환 구조
- 매수·매도 규칙, 투자 수익률, 백테스트 결과

Pattern B의 “싸다”는 **자기 과거 가격 상태 대비 극단적으로 침체되었다**는
뜻이다. 향후 Pattern D가 다룰 **기업가치 대비 싸다**와 같은 의미가 아니다.

패턴과 전략은 분리한다. Pattern B는 상태를 판단할 뿐이며, 이 상태를 이용한
진입·보유·청산 규칙은 이 문서의 범위가 아니다.

## 시간축 역할

현재 Pattern B는 월봉을 핵심, 주봉을 보조 시간축으로 사용한다.

- **월봉**: 장기 침체·과열 상태를 판단하는 핵심 시간축
- **주봉**: 월봉 상태의 극단성과 현재 가격 위치를 보조로 확인
- **일봉**: 월봉·주봉을 만드는 입력으로만 쓴다. 일봉 지표나 진입 타이밍 역할은 두지 않는다.

## 현재 지표

현재 상태 판정 규칙 V02는 아래 유지 지표 3개만 쓴다. 산식, PIT, 계산 불가 처리는
[지표 계약 V01](feature_contract_v01.md)을 따른다.

| 시간축 | 지표 | 관찰하는 개념 |
|---|---|---|
| 월봉 | 36개월 범위 위치 (`36M_RANGE_POSITION`) | 최근 36개월 가격 범위 안에서 현재 위치 |
| 월봉 | 월봉 24개월 이동평균 이격 (`MONTHLY_MA24_DISTANCE`) | 월봉 24개월 이동평균과의 이격 |
| 주봉 | 52주 범위 위치 (`52W_RANGE_POSITION`) | 최근 52주 가격 범위 안에서 현재 위치 |

연구 초기에 검토한 지표 후보 7개와 선택 과정은
[지표 선택 V01](../validation/feature_selection_v01.md) 등 연구 기록에 있다.

## 공식 상태

5개 상태의 개념 정의는 이 문서가 유지한다. 자동 판정에 쓰는 임계값과 결합 규칙은
[상태 판정 규칙 V02](../validation/state_rule_v02.md)를 따른다.

| 상태 토큰 | 의미 |
|---|---|
| `DEEP_DEPRESSED` | 장기 가격 사이클에서 극단적으로 침체된 상태 |
| `DEPRESSED` | 장기 가격 사이클에서 침체된 상태 |
| `NORMAL` | 어느 극단에도 가깝지 않은 상태 |
| `OVERHEATED` | 장기 가격 사이클에서 과열된 상태 |
| `EXTREME_OVERHEATED` | 장기 가격 사이클에서 극단적으로 확장된 상태 |

각 상태는 가격의 장기 극단성만 뜻한다. 매수·보유·매도 신호가 아니다.

## 구조 붕괴 위험과의 경계

Pattern B는 망하는 회사를 가려내는 패턴이 아니다. 가격이 침체되었는지
과열되었는지만 판단한다.

가치 함정(Value Trap)이나 구조 붕괴 위험은 Pattern B 범위 밖이다. 필요하면 별도의 적격성·위험
판단 층(Eligibility / Risk Layer)에서 다룬다. 예를 들면 다음과 같다.

- 극단적 저시가총액
- 극단적 유동성 부족
- 상장주식수 비정상 급증
- 구조 붕괴 위험 진단

이 문서는 위 항목의 임계값이나 필터를 정하지 않는다. 또한 장기 하락 중이라는
이유만으로 종목을 Pattern B 대상에서 제외하지 않는다. 그런 규칙은 Pattern B의
역발상 성격을 훼손할 수 있다.

## 범위 밖

- 적격성·위험 판단 층: 존재 여부와 기준을 정하지 않았다.
- Pattern B를 이용하는 전략 규칙과 백테스트: 전략 영역에서 다룬다.
