## 1. 목적과 범위

이 문서는 FastCore 현실적 백테스트의 공통 조건에 대한 당시 최종 추천안과 사용자
승인 결과를 보존한다. 승인된 조건은 `realistic_backtest_common_conditions_v01.md`에
공식 공통 실행조건으로 확정하도록 기록했다.

당시 확정 작업에서는 백테스트, 성과 계산, 실행 코드·러너·아티팩트 변경, 데이터
수집, `pytest`, V2 규칙 변경을 수행하지 않았다. 공통조건 확정과 실제 실행계약·
결과 생성은 별도 단계로 기록했다.

## 2. 이미 확인된 기준

다음 항목은 이번 승인 대상에서 제외하고 기존 공식 기준을 그대로 유지한다.

- 저장소는 `MarketDataRepositoryV2`를 사용한다.
- 과거 시점의 PIT 유니버스는 역사적 기준으로 채운다. 현재 종목 목록을 과거 시점에 방송하지 않는다.
- 가장 가까운 날짜로 대체하지 않으며, 필요한 결측은 명시적으로 실패·예외 처리한다.
- 전략은 `PATTERN_A_FAST_FINAL_STRATEGY_V02`를 사용하고 V2 규칙을 변경하지 않는다.
- 신호는 완료된 관측값으로 확정하고 `NEXT_LOCAL_TRADING_DAY_OPEN`에서 체결한다.
- 완료된 주간 신호가 확정된 뒤 도래하는 새로운 주의 첫 로컬 거래일 시가에서 신규 진입한다.
- Pre-PROGRESSED `Loss Guard`는 기존 -15% 규칙과 다음 로컬 거래일 시가 청산을 유지하며, Exit 3·Exit 4는 기존 월봉 신호 이후 다음 달 첫 로컬 거래일 시가 청산을 유지한다.
- 동일 종목 동시 보유, 피라미딩, 같은 시가의 청산 후 재진입은 허용하지 않는다.
- 역사적 매도 거래세는 실제 체결일과 시장에 따른 공식 세율을 적용하며, 매수에는 적용하지 않는다. 거래세 상태는 `확인됨`이다.

## 4. 승인 후 최소 보고 형식

전체 결과와 위 강건성 구간별로 다음 지표만 보고한다.

- 거래 횟수
- 총수익률
- CAGR
- MDD
- 평균·중앙 보유기간
- 투자 노출도
- 회전율
- 승률
- 손익비(payoff ratio)
- 기준일 미청산 포지션 수(`OPEN_AT_CUTOFF`)
- `UNRESOLVED` 예외 수와 영향 금액
- 비용 총액(수수료·거래세·슬리피지 영향)

`UNRESOLVED`가 하나라도 있으면 실행 결과에 예외 수, 영향 금액, `INCOMPLETE_REQUIRES_REVIEW` 상태를 함께 표시한다. `UNRESOLVED`를 정상 종가나 0으로 바꾸지 않는다.

집중도는 다음 세 가지로만 보고한다.

- 종목 집중도: 동일 종목에서 발생한 모든 독립 거래의 손익 기여를 종목 단위로 합산한 뒤, 누적 손익 기여 상위 10개 종목의 전체 손익 기여도
- 대형 수익 거래 집중도: 개별 종료 거래 기준 수익 기여 상위 10개 거래의 총이익 기여도
- 대형 손실 거래 집중도: 개별 종료 거래 기준 손실 기여가 가장 큰 10개 거래의 총손실 기여도

새로운 점수, 임계값, 종목 필터, 파라미터 탐색, 복잡한 집중도 지수는 추가하지 않는다.

## 5. 공식 수수료 자료의 최소 확인

수수료는 전 증권사 조사가 아니라 주요 온라인 거래 사례 2건만 확인했다.

- [키움증권 국내투자 시작하기·주식 FAQ](https://www1.kiwoom.com/h/domestic/stock/VStockMainView?dummyVal=0): HTS·홈페이지 현금 주식매매 수수료 0.015%를 안내한다.
- [미래에셋증권 고객자산배분전략 공식 자료](https://securities.miraeasset.com/public/hks4412/003/StrategyAugust.pdf): **과거 공식 자료 참고**. 다이렉트 계좌 국내주식 온라인 기본 수수료 0.014%를 안내한 자료이며, 현재 공식 수수료로 표현하지 않는다.

두 자료는 특정 사용자의 계좌·이벤트 조건을 재현하는 근거가 아니라, 온라인 국내주식 수수료의 현실적 범위를 확인하는 참고다. 미래에셋 자료는 과거 공식 자료 참고로만 취급하고 현재 수수료 체계로 사용하지 않는다. 따라서 최종 공통 가정은 계산이 단순하고 재현 가능한 0.015%로 둔다. 거래세는 위 승인표의 선택 항목이 아니며, 이미 확인된 역사 세율을 적용한다.

`q = 5,000,000원`은 종목당 총 매수 현금예산이다. 매수 체결가와 매수 수수료를 함께 고려하여 총 현금 유출이 `q` 이하가 되는 최대 정수 주식 수량을 산출한다. 매수 슬리피지는 체결가에 반영하며, 별도 예산 버퍼나 복잡한 추가 산식은 만들지 않는다.

## 6. 당시 별도 실행 전 제한 범위

문서 작성 당시에는 다음을 수행하지 않았다.

- FastCore 또는 Julia 백테스트 실행과 성과 계산
- V2 임계값 탐색, 새 필터, 새 시장 국면 모델 추가
- 실행 코드, 실행기, PIT 적재기, V2 문서, 결과 산출물 변경
- 외부 API 호출과 `pytest`
- Fundamentals Filter 조건 확정
- 이 문서의 승인 내용을 실제 실행계약·백테스트 결과로 승격

공통 실행조건은 별도 기준 문서에 확정했으며, 당시에는 실제 실행 전 Fundamentals
Filter와 별도 실행계약 검토를 완료해야 한다고 기록했다. 현재 이 문서는 추가 실행이나
승인을 요청하지 않는 역사 기록이다.
