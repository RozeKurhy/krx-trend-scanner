# Pattern A Fast Definition v0.1

================================================================================
0. 문서 상태
================================================================================
Phase: 13A — Pattern A Fast Definition
Status: PROVISIONAL — 이 문서는 인간 언어 수준의 개념 정의만 확정한다.
Base: `9a8013005a28af113fb10607cd493eba8ed32184`

이 문서는 알고리즘, Feature 공식, Threshold, Score 산식을 정의하지 않는다.
Pattern A Fast가 "무엇을 탐지하려는 전략인가"를 사람이 같은 언어로 이해하기
위한 Research Contract다. 구체적인 계산식과 수치는 13D~13G에서 결정한다.

--------------------------------------------------------------------------------
1. Purpose (목적)
--------------------------------------------------------------------------------
Pattern A Fast는 장기적으로 상승 전환을 시도할 수 있는 위치에 있는 종목을
월봉으로 확인하고, 실제 상승 전환 Setup과 Trigger는 주봉을 중심으로 탐지하며,
일봉은 해당 주봉 신호 이후 실제 진입 타이밍을 확인하는 보조 시간축으로
사용하는 전략이다.

핵심 목적은 기존 Pattern A보다 더 빠르게 유효한 상승 전환 가능성을
포착하는 것이다.

중요: "빠르다"는 이유만으로 좋은 신호로 보지 않는다. Pattern A Fast의
목표는 EARLY가 아니라 **EARLY + STRUCTURALLY VALID**다.

공식 명칭은 **Pattern A Fast**이며, 설명명은 **Monthly Regime + Weekly
Trigger + Daily Timing**이다. Pattern A v0.3 / Pattern A v1 / Pattern A2 /
Pattern A 개선판 같은 이름으로 취급하지 않는다. 기존 Pattern A를 대체하거나
수정하는 것이 아니라 시간축과 투자 스타일이 다른 독립 파생 전략이기
때문이다.

--------------------------------------------------------------------------------
2. Relationship to Pattern A (기존 Pattern A와의 관계)
--------------------------------------------------------------------------------
기존 Pattern A: `DONE`, `FROZEN`, Conservative Structural Detector.
Pattern A Fast: Independent Fast Detector.

* Pattern A의 역할: 월봉 + 주봉 기반으로 충분히 확인된 장기 상승 초입을
  보수적으로 탐지.
* Pattern A Fast의 역할: 월봉에서 장기 환경을 확인한 뒤 주봉에서 더 빠른
  전환 Setup / Trigger를 탐지.

가능한 정상 조합 예 (Pattern A Stage → Pattern A Fast Lifecycle):
* Pattern A `BASE` ↔ Pattern A Fast `TRIGGER`
* Pattern A `TRANSITION` ↔ Pattern A Fast `TREND`
* Pattern A `EARLY_TREND` ↔ Pattern A Fast `EXTENDED`

이러한 불일치는 오류가 아니다. 두 Pattern은 시간축과 목적이 다르므로
서로 다른 상태를 반환할 수 있다.

**Pattern A를 정답 Label로 사용하지 않는다.** Pattern A Fast의 성공 여부를
"나중에 Pattern A가 잡았는가"만으로 정의하지 않는다. Pattern A는 **Lead
Time 비교용 Benchmark**로 사용한다. 즉 Fast Trigger Date와 Pattern A
`TRANSITION`/`EARLY_TREND` Date를 비교할 수는 있지만, Pattern A가 잡지
못한 상승 종목이라고 해서 자동으로 Pattern A Fast 실패로 정의하지 않는다.
향후 Ground Truth에서는 실제 가격 구조와 사후 validation outcome을
독립적으로 검토한다.

--------------------------------------------------------------------------------
3. Timeframe Responsibility (시간축 역할 Definition)
--------------------------------------------------------------------------------
Pattern A Fast는 다음 3계층 구조를 가지며, 각 시간축의 책임을 엄격하게
분리한다.

```
MONTHLY REGIME → WEEKLY STRUCTURE / TRIGGER → DAILY TIMING
```

--------------------------------------------------------------------------------
4. Monthly Regime Definition (월봉 역할)
--------------------------------------------------------------------------------
월봉의 질문: "이 종목은 지금 빠른 상승 전환을 연구할 만한 장기 위치에
있는가?"

월봉은 Trigger를 생성하지 않는다. 월봉의 역할은 **ENVIRONMENT / REGIME
FILTER**다.

월봉이 확인할 개념 (구체적 수치화는 13D에서 결정):
* 장기 하락 또는 장기 조정 여부
* 장기 바닥권 또는 회복 가능 위치 여부
* 장기 이동평균 구조
* 장기 가격 range 내 위치
* 이미 지나치게 상승한 상태인지
* 장기적으로 아직 구조적 위험이 너무 큰 상태인지

이번 13A에서는 구체적인 MA 기간, range threshold, 하락률 threshold 등을
정의하지 않는다.

--------------------------------------------------------------------------------
5. Weekly Core Definition (주봉 역할)
--------------------------------------------------------------------------------
주봉이 Pattern A Fast의 핵심 시간축이다.

주봉의 질문: "장기 하락 또는 정체 상태에서 실제 상승 전환 구조가
만들어지기 시작했는가?"

향후 연구 후보 개념 (13E에서 채택 여부 결정, 이번 단계에서는 확정하지
않음):
* 하락 속도 둔화
* 주봉 저점 상승 / 주봉 고점 상승
* 주봉 이동평균 평탄화 / 상승 전환
* 가격의 주요 주봉 이동평균 회복
* 중기 박스 상단 접근 또는 돌파
* 주봉 변동성 변화
* 주봉 거래량 / 거래대금 변화
* 주봉 구조의 higher low / higher high progression

구체적인 계산식과 threshold는 13E Weekly Trigger Feature Research에서
결정한다.

--------------------------------------------------------------------------------
6. Daily Timing Definition (일봉 역할)
--------------------------------------------------------------------------------
일봉은 Pattern 자체를 결정하지 않는다.

일봉의 질문: "주봉 구조가 유효하다는 전제하에 현재 단기 진입 위치가
적절한가?"

향후 고려 가능한 개념 (13F에서 결정): 돌파 직후, 눌림, 재돌파, 단기
이동평균 이격, 단기 과열, 최근 저점 이탈, 거래대금 동반 여부.

이번 Phase 13A에서 Daily Timing 공식이나 threshold는 만들지 않는다.
Daily는 **ENTRY TIMING SUPPORT LAYER**로 정의한다.

--------------------------------------------------------------------------------
7. Target Zone (Pattern A Fast가 잡고 싶은 핵심 구간)
--------------------------------------------------------------------------------
원하는 구간: 장기 하락 또는 조정이 상당 부분 진행된 이후, 월봉상 지나치게
위험하거나 지나치게 진행된 위치가 아니고, 주봉에서 하락 구조가 둔화되며
저점 / 이동평균 / 가격 구조가 개선되기 시작하고, 상승 전환 가능성이 실제
주봉 구조에 나타나는 시점.

핵심: 완전히 상승 추세가 확인된 뒤가 아니라 상승 추세가 "만들어지는
과정"을 잡는다.

--------------------------------------------------------------------------------
8. Too Early
--------------------------------------------------------------------------------
`TOO_EARLY`의 인간 언어 정의: 아직 구조적 증거 없이 가격만 단기적으로
움직인 상태.

예: 월봉상 장기 하락 압력이 여전히 강함 / 주봉 하락 추세가 아직 명확히
유지됨 / 단순 1~2주 반등만 존재 / 주봉 저점 구조 개선이 없음 / 이평선
구조 개선 없이 가격만 단기 급등 / 장기 저항 바로 아래의 일시적 반등 /
거래 증가 없이 단기 기술적 반등만 발생.

핵심: "가격이 올랐다"만으로 Trigger가 아니다.

--------------------------------------------------------------------------------
9. Setup
--------------------------------------------------------------------------------
`SETUP`은 아직 Trigger가 아니다.

인간 언어 정의: 상승 전환 가능성을 보여주는 주봉 구조 변화가 시작되었으나,
아직 실제 전환을 확정할 정도의 가격 구조가 완성되지 않은 상태.

예: 하락 기울기 둔화 / 저점 방어 / 주봉 MA 평탄화 시작 / range 상단
접근 / 주봉 고점 구조 개선 시도.

SETUP은 관찰 대상이지 매수 신호가 아니다.

--------------------------------------------------------------------------------
10. Trigger
--------------------------------------------------------------------------------
`TRIGGER`가 Pattern A Fast의 핵심 연구 대상이다.

인간 언어 정의: 월봉 환경이 허용 가능한 상태에서 주봉 가격 구조가 단순
반등을 넘어 상승 전환 가능성이 실제로 나타난 최초의 유의미한 시점.

TRIGGER는 상승이 완전히 확인된 시점보다 빨라야 하지만, 단순 반등
수준보다는 충분한 구조적 증거가 있어야 한다.

즉 개념적 목표는:

```
TOO_EARLY  <  TRIGGER  <  Pattern A의 보수적 확인 시점
```

단 이것은 개념적 목표이며, 모든 종목에서 반드시 Pattern A보다 먼저
발생해야 한다는 의미는 아니다.

--------------------------------------------------------------------------------
11. Trend
--------------------------------------------------------------------------------
`TREND`는 Fast Trigger 이후 주봉 상승 구조가 실제로 지속되고 있는 상태다.

이 시점은 Pattern A의 `TRANSITION` 또는 `EARLY_TREND`와 겹칠 수 있다.
Fast 관점에서는 더 이상 최초 진입 Trigger가 아니라 진행 중인 추세
상태로 본다.

--------------------------------------------------------------------------------
12. Extended
--------------------------------------------------------------------------------
`EXTENDED`는 Pattern A Fast 관점에서 이미 초기 진입 구간을 상당 부분
지나간 상태다.

중요: EXTENDED가 나쁜 종목이라는 뜻이 아니다. Pattern A에서는
`EARLY_TREND`일 수도 있고, 장기 투자 관점에서는 여전히 유효할 수 있다.
단 Fast Strategy의 신규 진입 관점에서는 Risk / Reward가 악화된 상태로
해석한다.

--------------------------------------------------------------------------------
13. False Trigger
--------------------------------------------------------------------------------
`FALSE_TRIGGER`의 인간 언어 정의: TRIGGER 직후 다시 기존 하락 구조로
복귀하는 경우.

예: 주봉 돌파가 빠르게 실패 / 주봉 저점 구조가 무너짐 / 상승 전환으로
보였으나 다시 장기 range 하단으로 회귀 / 지속적인 상승 구조로 연결되지
못한 일시적 반등.

향후 False Trigger 판정 window(예: 4주/8주/12주)는 13H Lead Time /
Failure Analysis에서 연구한다. 13A에서는 이러한 숫자를 공식 threshold로
고정하지 않는다.

--------------------------------------------------------------------------------
14. Too Late
--------------------------------------------------------------------------------
`TOO_LATE`는 주봉 전환이 이미 충분히 진행된 이후 뒤늦게 Fast Trigger가
발생하는 경우다.

Fast 전략의 존재 이유는 기존 Pattern A보다 빠른 탐지이므로, Pattern A
`EARLY_TREND` 이후에야 Fast Trigger가 발생하는 구조가 반복된다면 Fast
전략의 가치가 낮다고 본다. 단 개별 사례 하나만으로 실패 판정하지 않고
향후 cohort 전체에서 통계적으로 평가한다.

--------------------------------------------------------------------------------
15. Success Definition
--------------------------------------------------------------------------------
`SUCCESSFUL FAST SIGNAL`은: Trigger 이후 주봉 상승 구조가 의미 있게
유지되거나 발전하고, 기존 장기 하락 / 정체 구조로 즉시 복귀하지 않으며,
Pattern A보다 유의미한 선행 탐지 가능성을 제공하는 신호.

중요: 성공을 단순 수익률로만 정의하지 않는다. 예를 들어 "Trigger 후
+10%" 같은 단일 수익률 threshold를 13A에서 사용하지 않는다. 구조적
성공과 투자 성과는 향후 별도 검증한다.

--------------------------------------------------------------------------------
16. Validation Questions (Fast의 가치 측정 기준)
--------------------------------------------------------------------------------
향후 검증에서 최소 다음 축을 측정한다:
* Lead Time to Pattern A `TRANSITION`
* Lead Time to Pattern A `EARLY_TREND`
* False Trigger Rate
* Failure after Trigger
* Trigger 이후 Stage progression
* Trigger 이후 최대 adverse excursion
* Trigger 이후 최대 favorable excursion

단 이번 단계에서는 어떤 수치를 PASS 기준으로 할지 정하지 않는다(예:
"평균 6주 이상 빨라야 성공" 같은 threshold는 아직 금지). 먼저 실제
Ground Truth를 만들어 분포를 확인한 뒤 결정한다.

--------------------------------------------------------------------------------
17. Provisional Lifecycle (PROVISIONAL ONLY)
--------------------------------------------------------------------------------
13B Stage / Lifecycle Contract 연구의 출발점으로 다음 lifecycle을
"초안"으로 문서화한다.

```
WATCH → SETUP → TRIGGER → TREND → EXTENDED
```

이번 13A에서 공식 Frozen Stage로 확정하지 않는다. **PROVISIONAL ONLY.**
13B에서 실제 Human Ground Truth와 함께 Stage 명칭 / 의미 / 전이 관계를
공식 검토한다.

--------------------------------------------------------------------------------
18. Candidate Concept (Non-Frozen)
--------------------------------------------------------------------------------
이번 단계에서는 Candidate 공식 정의를 Freeze하지 않는다. 다만 연구
방향으로 다음 개념만 기록한다:

* `WATCH` — 관찰
* `SETUP` — 관심 후보
* `TRIGGER` — Fast Candidate 핵심
* `TREND` — 진행 중
* `EXTENDED` — Late

Candidate State의 공식 semantics는 13G Production Contract에서 확정한다.

--------------------------------------------------------------------------------
19. Ground Truth Label Vocabulary
--------------------------------------------------------------------------------
13C Human Ground Truth Dataset에서 사람이 차트를 검토할 때 사용할 초기
vocabulary:

* `GOOD_TRIGGER` — 월봉 환경이 허용 가능하고 주봉 구조 전환이 이후
  실제로 유지/발전한, 이상적인 Fast Trigger 사례.
* `BORDERLINE_TRIGGER` — Trigger 조건은 성립하지만 이후 진행이
  약하거나 불확실하여 GOOD/FALSE 어느 쪽으로도 단정하기 애매한 사례.
* `FALSE_TRIGGER` — Trigger 직후 기존 하락/횡보 구조로 복귀하거나
  돌파가 빠르게 실패한 사례.
* `TOO_EARLY` — 구조적 증거 없이 가격만 단기적으로 움직여 아직 Trigger로
  볼 수 없는 사례.
* `TOO_LATE` — 주봉 전환이 이미 충분히 진행된 뒤 뒤늦게 포착되어 Fast
  전략으로서 선행 가치가 낮은 사례.
* `EXTENDED` — 이미 초기 진입 구간을 상당 부분 지나가 신규 진입 관점의
  Risk/Reward가 악화된 사례.
* `NO_SETUP` (필요 시 추가) — 관찰 시점 기준 SETUP에 해당하는 구조
  변화조차 나타나지 않은 사례.

각 label의 구체 threshold는 여기서 작성하지 않는다.

--------------------------------------------------------------------------------
20. Point-In-Time Rules
--------------------------------------------------------------------------------
Pattern A Fast도 기존 프로젝트와 동일하게 Point-In-Time 원칙을 따른다.

특정 historical week의 판단에는 그 주 시점까지 확정된 데이터만 사용한다.
다음은 Trigger 계산에 사용하지 않는다: 미래 주가, 미래 거래량, 미래
Stage, 미래 Pattern A 판정, 미래 수익률. 미래 데이터는 오직 사후
Validation에서만 사용한다.

--------------------------------------------------------------------------------
21. Separation from Investability / Flow / RS
--------------------------------------------------------------------------------
**Relative Strength(Phase 12)와의 관계**: Phase 13은 Phase 12와
독립적으로 진행 가능하다. Pattern A Fast Core는 Phase 12 Relative
Strength가 없어도 계산 가능해야 한다. RS 데이터가 없으면 Pattern A
Fast 자체가 계산 불가능한 구조는 금지한다. 향후 RS는 Independent
Confirmation Axis 또는 Supporting Evidence로 검토할 수 있으나, Phase
13A에서는 RS를 Pattern A Fast 필수 조건으로 정의하지 않는다.

**Investability / Flow와의 관계**: Pattern A Fast 구조 탐지와 Market
Cap, Trading Value hard filter, Foreign Flow, Relative Strength는
분리한다. Pattern Detection과 Investability / Confirmation을 섞지
않는다. 즉 `Pattern A Fast TRIGGER`이면서 동시에
`FILTERED_MARKET_CAP`일 수 있으며, 이것은 정상적인 결과다.

--------------------------------------------------------------------------------
22. Non-Goals (13A의 비목표)
--------------------------------------------------------------------------------
이번 단계에서 절대 하지 않는 것:
* MA12 > MA24 같은 공식 확정
* 8주 breakout threshold 확정
* 12주 range threshold 확정
* Volume ratio threshold 확정
* Fast Score 0~100 설계
* TRIGGER 점수 cutoff 설계
* Daily READY 조건 설계
* False Trigger 기간 숫자 확정
* Backtest / Optimization
* 전체 시장 스캔
* 실제 Candidate 생성

--------------------------------------------------------------------------------
23. Synthetic Examples
--------------------------------------------------------------------------------
실제 ticker는 아직 사용하지 않는다.

**Example A — GOOD FAST TRIGGER 후보**
* Monthly: 장기 바닥권 허용
* Weekly: 하락 둔화 → SETUP → 구조 돌파
* Daily: 과열 아님
* 결과: GOOD FAST TRIGGER 후보

**Example B — TOO_EARLY**
* Monthly: 장기 하락 진행 중
* Weekly: 2주 급반등
* Daily: 강한 양봉
* 결과: TOO_EARLY

**Example C — EXTENDED / TOO_LATE**
* Monthly: 상승 추세 상당 부분 진행
* Weekly: 이미 장기 이격 확대
* Daily: 신고가 급등
* 결과: EXTENDED / TOO_LATE
