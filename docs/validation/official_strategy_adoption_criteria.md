# 공식 전략 공통 채택 기준

작성일: 2026-09-28 KST

## 1. 목적과 적용 범위

이 문서는 A FAST Core V2를 포함해 프로젝트에서 공식 전략으로 검토하는 모든 전략과 후보에 적용하는 공통 최소 기준이다. 백테스트 실행·데이터·PIT·체결 원칙은 [`backtest_common_rules.md`](backtest_common_rules.md)를 따르고, 전략 생애주기와 기본 전략 분리 원칙은 [`strategy_lifecycle.md`](../strategies/strategy_lifecycle.md)를 따른다.

표준 기간은 `backtest_common_rules.md` §3.1의 P1, P2-1, P2-2, P3-1, P3-2다. 각 기간의 정확한 거래일 해석, 자료 근거 및 실행 계약은 해당 공통 원칙과 실행 계획에 따른다.

전략별 사전 계획은 실행 조건과 추가 진단을 정할 수 있다. 다만 공식 전략 재심사에서는 이 공통 필수 통과 기준을 완화하지 않는다. 결과를 확인한 뒤 이 기준을 변경하지 않으며, 변경이 필요하면 새 기준 개정판과 새 검증 계획을 봉인한다.

## 2. 공통 필수 통과 기준

모든 기준은 다섯 표준 기간 각각에 적용한다. 개수, 종목 식별 정보, 상태값, 날짜 및 범주형 무결성 값은 정확히 일치해야 한다.

### 필수 통과 기준 A — 무결성

다음 구조적 오류가 없어야 한다.

- PIT 유니버스·종목 식별 정보 위반
- 미래정보 참조 또는 기준 종료일 뒤 신규 진입
- 포지션 생애주기 위반
- 종목 식별 정보 오류, 중복 또는 기간 겹침
- 현금 보존·정산 오류
- 계약에 없는 보유 종목 수 제한
- 결과 판정에 영향을 줄 수 있는 미해결 구조적 데이터 문제

필수 원장과 계약의 개수, 종목 식별 정보, 상태값, 날짜는 정확히 대조한다. 실행 계약에서 판정할 수 있는 검사는 모든 기간에서 통과해야 한다.

### 필수 통과 기준 B — 실행 비용

공식 채택용 핵심 성과에는 매수·매도 수수료와 슬리피지를 100% 반영한다. 어느 한쪽이라도 누락된 체결이 있으면 통과하지 못한다.

거래세·매도세는 공식 채택 기준과 공식 성과 산식에서 제외한다. 거래세 근거 자료가 없다는 이유만으로 심사를 중단하거나 `CHECK_REQUIRED` 또는 `HOLD`로 판정하지 않는다. 거래세 자료가 있고 참고 민감도 분석이 필요하면 별도 진단으로 보고할 수 있지만, 수수료와 슬리피지를 반영한 공식 수익률·CAGR·MDD, 현금 흐름 및 기준 판정을 대체하거나 바꾸지 않는다. 일부 기간에만 거래세를 섞어 공식 지표를 계산하지 않는다.

### 필수 통과 기준 C — 수익성

P1, P2-1, P2-2, P3-1, P3-2 각각에서 수수료와 슬리피지를 반영하고 거래세를 제외한 기준으로 다음을 모두 충족한다.

```text
총수익률 > 0
CAGR > 0
```

### 필수 통과 기준 D — 포트폴리오 MDD

다섯 기간 각각에서 수수료와 슬리피지를 반영한 일별 포트폴리오 자산가치 곡선의 MDD가 다음을 충족한다.

```text
MDD >= -35%
```

개별 거래 MAE나 평균 손실로 대체하지 않는다.

### 필수 통과 기준 E — 현금 부족

다섯 기간 각각에서 다음 현금 부족 진입 누락률을 충족한다.

```text
cash_shortage_skip_rate < 55%
```

정확히 `55.00%`는 통과하지 못한다.

분모는 **포트폴리오 자금 배분 전에 사전 확정된 공식 전략 CONTROL 신호/거래 원장** 중 전략 규칙, PIT, 생애주기, 정확한 진입 체결가 및 정수주식 조건을 만족해 현금만 충분하면 실제 주문할 수 있었던 진입 시도 수다. 분자는 그중 오직 현금 부족으로 `SKIPPED_CASH_UNAVAILABLE` 처리된 수다. 종목 식별 정보·가격·생애주기 등 현금 이외 사유의 실패는 분자나 분모에 섞지 않는다.

원장 확정과 포트폴리오 자금 배분은 순서대로 분리한다. 현금 부족이 발생해도 전략 신호를 다시 생성하거나 종목별 전략 상태를 재생하지 않으며, 사전 확정 원장에 없는 후속 시도나 반복 신호를 새 독립 기회로 추가하지 않는다. 현금 부족에 따라 신호 자체가 달라지는 동적 자본 의존형 실행은 별도 민감도 연구로만 다루고 공식 기준 E에는 사용하지 않는다.

### 필수 통과 기준 F — 결과 유효성

핵심 성과를 신뢰할 수 있어야 한다. 다음 문제가 판정에 영향을 줄 정도로 중대하면 통과하지 못한다.

- 종료 시점 평가의 미해결 값이 수익률 또는 MDD에 영향을 줄 수 있음
- 일별 자산가치 평가 공백으로 핵심 지표를 계산할 수 없음
- 가장 가까운 날짜 값·대리값·임의 앞 값 이월 등 허용되지 않은 가격 대체. 단, 공식 거래 상태 근거로 해당 거래일의 거래정지/비거래가 확인된 경우 일별 포트폴리오 평가에 한해 공통 실행 원칙의 제한적 직전 종가 유지를 허용한다.
- 성과를 이유로 한 사후 종목 제거
- 결론을 바꿀 수 있는 미해결 구조·계산 오류

평가 불가 값은 임의 대체하지 말고 `CHECK_REQUIRED` 또는 `UNRESOLVED`로 남긴다. 공식 거래정지/비거래가 확인되지 않은 단순 가격 결측은 직전 종가로 대체할 수 없다. 허용된 평가용 직전 종가 유지의 근거와 사용 내역은 감사 원장에 남긴다.

## 3. 현금 부족률 진단 해석

기준 E는 최소 실행 가능성 기준이다. 통과가 좋은 자본 효율을 뜻하지 않는다. 현금 부족 진입 누락률은 반드시 별도 숫자로 보고하고, 설명이 유용하면 다음 참고 구간을 함께 쓸 수 있다.

| 현금 부족 진입 누락률 | 참고 해석 |
|---|---|
| `<20%` | 양호 |
| `20% ≤ 누락률 <35%` | 자본 제약 존재 |
| `35% ≤ 누락률 <55%` | 자본 제약 큼 |
| `≥55%` | 기준 E FAIL |

세 구간 표시는 참고용이며 추가 필수 통과 기준이 아니다.

## 4. 필수 보고와 최종 판정

각 검증 기간에서 기준별 상태와 근거를 남긴다. 최소한 다음을 보고한다.

- 총수익률, CAGR, 포트폴리오 MDD
- 현금 부족률과 분자·분모, 현금 활용도
- 수수료·슬리피지 적용 여부
- 최대·평균 동시 보유, 회전율, 미청산·미해결 수
- 결과 해석에 필요한 거래·기간·종목 집중도 진단

필요한 핵심 값이 확정되지 않으면 해당 기준을 `CHECK_REQUIRED`로 표시하고 어떤 자료가 왜 불완전한지 기록한다.

- `OFFICIAL_STRATEGY_ADOPTED`: A~F가 다섯 검증 기간 모두 PASS하고 판정에 영향을 줄 중대한 구조적 문제가 없음.
- `NOT_ADOPTED`: 필요한 증거가 완결됐으나 하나 이상의 필수 통과 기준이 FAIL.
- `HOLD`: 채택 판단에 필요한 핵심 증거가 미해결 또는 불완전함. 거래세 근거 자료 누락만으로는 HOLD 사유가 되지 않음.

## 5. V2 기준점과 기본 전략 분리

A FAST Core V2를 포함한 기존 공식 전략과 신규 후보에 동일 기준을 적용한다. 새 전략이 V2보다 모든 지표에서 우수해야 공통 기준을 통과하는 것은 아니다. V2 대비 우위와 기본 전략 교체 여부는 별도 비교·승격 단계에서 판단한다.

공식 전략 채택은 프로젝트에서 사용할 수 있는 공식 전략으로 인정하는 결정이며, 기본 전략 승격이나 교체를 자동으로 뜻하지 않는다.

## 6. 과거 검증 기록

이 기준은 적용 이후의 공식 전략 심사에 사용한다. 이전 실행 당시 별도 기준으로 봉인된 검증 계획과 산출물은 당시 실행 기록으로 보존하며 이 문서에 맞춰 소급 수정하지 않는다. 과거 결과를 새 기준으로 심사할 필요가 있으면 기존 기록은 유지하고 재심사 범위와 새 기준 개정판을 별도로 기록한다.
